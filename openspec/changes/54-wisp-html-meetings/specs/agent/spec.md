## ADDED Requirements

### Requirement: Отказы команды `spook topic` для страниц Wisp
Команда `spook topic` SHALL отклонять рабочую Заметку идущей Сессии, Заметку с Темой, пустую Тему, отсутствующий файл, старый Markdown, файл вне `html/` выбранного Wisp, ссылку на другую страницу и чужую страницу Wisp. Причина пишется в поток ошибок, код завершения 1. Отказ сохраняет имя и содержимое страницы.

#### Scenario: Страница недоступна для изменения Темы
- **WHEN** пользователь вызывает `spook topic` для рабочей Заметки, отсутствующей страницы, ссылки, страницы вне Wisp, старого Markdown или чужой страницы Wisp
- **THEN** код 1, причина в потоке ошибок, никакая страница не меняется

#### Scenario: Тема уже есть или передана пустая Тема
- **WHEN** пользователь пытается изменить указанную Тему или задаёт Тему из одних пробелов
- **THEN** отказ называет причину, прежний адрес и содержимое Заметки сохранены

## MODIFIED Requirements

### Requirement: Заметка завершённой Сессии встаёт в очередь Агента
После завершения Сессии с Репликами и успешного обновления раздела «Встречи» Spook SHALL поставить опубликованную HTML-Заметку в очередь Агента один раз. Сессия без Реплик или незавершённая публикация запуск исключают.

#### Scenario: После «Стоп» Агент запущен один раз
- **GIVEN** идёт Встреча, начатая 2026-11-06 в 14:02, распознана Реплика «Реплика.»
- **WHEN** пользователь нажимает «Стоп»
- **THEN** Агент вызван ровно один раз — для Заметки «2026-11-06 14-02 Встреча»

#### Scenario: Агент получает окончательное имя Заметки
- **GIVEN** идёт Встреча, во время Сессии введена Тема «Репликация в Raft»
- **WHEN** пользователь нажимает «Стоп»
- **THEN** Агент вызван для страницы «2026-11-06 14-02 Репликация в Raft» в Wisp, и Журнал Агента назван по этому имени

#### Scenario: Сессия без Реплик
- **GIVEN** идёт Встреча, звук распознан пустым текстом
- **WHEN** пользователь нажимает «Стоп»
- **THEN** Агент и программа уведомлений не вызваны, блок Агента на экране пуст

### Requirement: Очередь Агента переживает перезапуск службы
После перезапуска службы опубликованные HTML-Заметки Встреч, ждавшие в очереди, SHALL запуститься в прежнем порядке. Прерванный запуск для Встречи SHALL стать ошибкой «Агент прерван перезапуском службы» с уведомлением без повторного запуска. Транскрипт его Заметки проверяется и восстанавливается, уже написанная Выжимка остаётся. Служба SHALL пропускать задачи прежних Заметок Markdown, в том числе Лекций, сохраняя их Заметки без изменений.

#### Scenario: Перезапуск службы во время работы Агента
- **GIVEN** Агент работает над Заметкой `2026-11-06 14-02 Встреча`: написал Выжимку «Про тесты.» и переписал Транскрипт; Заметка `2026-11-06 15-02 Встреча` ждёт в очереди
- **WHEN** служба перезапущена
- **THEN** для первой Заметки показаны «Агент прерван перезапуском службы» и «Агент изменил Транскрипт — возвращён исходный.», в ней Выжимка и исходный абзац «14:02 Собеседники: Первая встреча.»; заново Агент для неё не вызван
- **AND** Агент вызван для второй Заметки и дошёл до «готово»
- **AND** уведомления: «Ошибка Агента» с текстом «2026-11-06 14-02 Встреча: Агент прерван перезапуском службы», затем «Выжимка готова» с текстом «2026-11-06 15-02 Встреча»

#### Scenario: В сохранённой очереди есть прежние задачи Лекций
- **GIVEN** до обновления в очереди остались Заметки Встреч и задачи `lecture`, одна из которых была в работе
- **WHEN** служба запускается после обновления
- **THEN** она восстанавливает задачи Встреч в прежнем порядке
- **AND** она не запускает Агента для старых Заметок Лекций и не переписывает их по сохранённой копии Транскрипта

#### Scenario: До перехода осталась задача для Markdown
- **GIVEN** в сохранённой очереди задача для `.md` и задача для HTML-Заметки Wisp
- **WHEN** служба запускается
- **THEN** она восстанавливает задачу для HTML, прежняя Заметка Markdown сохраняет путь и содержимое

### Requirement: Охрана Транскрипта
Spook SHALL охранять HTML-раздел «Транскрипт» опубликованной Заметки и восстанавливать его исходное содержимое при изменении. Для незавершённого запуска снимок HTML SHALL храниться временно в `.spook/` внутри Wisp. В сведениях очереди вне Хранилища хранится путь к снимку. После завершения или восстановления запуска снимок удаляется.

#### Scenario: Агент не тронул Транскрипт
- **WHEN** Агент написал Выжимку и не менял Транскрипт
- **THEN** на экране нет сообщений о Транскрипте, в Журнале Агента нет строки «Охрана Транскрипта»

#### Scenario: Агент переписал Транскрипт
- **GIVEN** на время работы Агента содержимое раздела «Транскрипт» изменено
- **WHEN** Spook завершает запуск или восстанавливает его после перезапуска службы
- **THEN** в Заметку возвращён исходный HTML-раздел с Репликами и Отметками, пользователь видит предупреждение
- **AND** в сохраняемых служебных сведениях вне Wisp нет текста Транскрипта

### Requirement: Стёртые заголовок и Заметка восстанавливаются
Если во время запуска Агента исчезла страница или повреждён раздел «Транскрипт», Spook SHALL восстановить Заметку из временного снимка в Wisp по прежнему адресу и сообщить о восстановлении.

#### Scenario: Агент стёр заголовок «Транскрипт»
- **GIVEN** перед запуском сохранён снимок HTML
- **WHEN** на странице утрачен раздел «Транскрипт»
- **THEN** по прежнему адресу снова доступна страница с исходным Транскриптом и свойствами Встречи

#### Scenario: Агент удалил Заметку
- **WHEN** опубликованная HTML-страница исчезает во время запуска
- **THEN** Spook восстанавливает Заметку с её свойствами и Транскриптом по прежнему адресу, пользователь видит сообщение о восстановлении

### Requirement: Для Заметки Встречи ведётся Журнал Агента
Журнал Агента SHALL храниться вне Хранилища. В нём сохраняются команда запуска, типы событий, код возврата, исход и причина сбоя. Служба SHALL исключать из Журнала текст Транскрипта, Выжимки и ответа Codex. Повторный запуск для той же страницы SHALL дописываться в тот же Журнал.

#### Scenario: Журнал Агента после неудачного запуска
- **GIVEN** вывод Codex содержит тип события и текст из Встречи
- **WHEN** запуск завершается ошибкой
- **THEN** Журнал содержит команду, типы событий, код и причину завершения, текста Реплик, Выжимки и ответа Codex в нём нет

#### Scenario: Повторный запуск дописывается в тот же Журнал Агента
- **WHEN** первая Выжимка готова, повторный запуск выбранной моделью завершился с ошибкой
- **THEN** один Журнал Агента содержит оба запуска по порядку, их модели, effort и причины ошибок

### Requirement: Словарь терминов и списки заметок для Агента Встречи
Spook SHALL передать Агенту через стандартный ввод выбранный Скилл, дату, имеющуюся Тему, Транскрипт, Словарь терминов и названия связанных страниц из индекса Wisp с их относительными HTML-адресами. Содержимое соседних страниц и сама обрабатываемая Заметка в списке отсутствуют.

#### Scenario: Имена заметок без содержимого
- **GIVEN** в индексе Wisp есть «План релиза», в Словаре терминов — «Kubernetes»
- **WHEN** работает Агент
- **THEN** во входе есть «Kubernetes», «План релиза» и относительный адрес этой страницы, текста соседней страницы нет

### Requirement: Применение Темы из ответа Codex
Spook SHALL принимать предложенную Тему только для Заметки без Темы и только вместе с корректной Выжимкой. Очищенная Тема SHALL появиться на странице, её адрес сохраняется.

#### Scenario: Написавший Выжимку Агент предложил Тему
- **GIVEN** опубликована Встреча без Темы
- **WHEN** Codex возвращает Выжимку и Тему «Репликация в Raft»
- **THEN** в заголовке и поиске Wisp видна новая Тема, прежний адрес открывает тот же Транскрипт и новую Выжимку

#### Scenario: Пользователь уже задал Тему
- **WHEN** Codex вернул другую Тему для Заметки с Темой
- **THEN** Выжимка обновлена, Тема пользователя сохранена

### Requirement: Команда `spook topic` для завершённой Заметки
Команда `spook topic <Заметка> <Тема…>` SHALL задать Тему завершённой Заметке без Темы, вывести прежний путь к опубликованной HTML-странице и завершиться с кодом 0. Применяются очистка Темы и ограничение в 80 знаков. Слова можно передавать отдельными аргументами.

#### Scenario: Пользователь называет Заметку без Темы
- **GIVEN** опубликована Встреча без Темы
- **WHEN** пользователь вызывает `spook topic "<путь к HTML-Заметке>" "Репликация в Raft"`
- **THEN** на странице видна Тема «Репликация в Raft», команда печатает прежний путь, код 0

#### Scenario: Тема очищается
- **WHEN** Тема передана как ` Raft:<табуляция>"репликация" <журнала>/логов? #1 *|\ `
- **THEN** Заметка названа «2026-11-06 14-02 Raft репликация журнала логов 1»

#### Scenario: Длинная Тема отдельными словами
- **WHEN** Тема передана отдельными словами: Распределённые системы — консенсус, репликация журнала, снимки состояния, перевыборы лидера и членство в кластере
- **THEN** Заметка названа «2026-11-06 14-02 Распределённые системы — консенсус, репликация журнала, снимки состояния, перевы»

#### Scenario: Тема повторяет имя другой Заметки
- **GIVEN** в Wisp есть страница «2026-11-06 14-02 Raft» и Заметка Встречи без Темы
- **WHEN** пользователь задаёт второй Заметке Тему «Raft»
- **THEN** обе страницы читаются по прежним адресам, первая сохранила имя и содержимое

**Reason**: Путь проверяется по опубликованным страницам Wisp.
