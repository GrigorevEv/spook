## MODIFIED Requirements

### Requirement: Файл настроек
Spook SHALL читать настройки из файла TOML `$XDG_CONFIG_HOME/spook/settings.toml`, а без `XDG_CONFIG_HOME` — из `~/.config/spook/settings.toml`. Команды `spook serve`, `spook prepare` и `spook topic` принимают другой файл через `--settings`. Отсутствующий ключ SHALL сохранять значение по умолчанию, `~` в путях разворачивается в домашний каталог. Корень Хранилища задаёт ключ `wisp`. Старые `[meeting] folder`, раздел `[lecture]` и настройки Вики `wiki` и `[programs] wiki` SHALL игнорироваться.

#### Scenario: Частичный файл меняет только указанные ключи
- **GIVEN** в файле настроек `port = 9000` и `auto_stop_minutes = 7`, `wisp = "~/my-wisp"`, в `[meeting]` — `effort = "medium"`, в `[programs]` — `codex = "/opt/codex/bin/codex"`
- **WHEN** Spook читает настройки
- **THEN** порт — 9000, время автостопа — 7 минут, корень Wisp — `my-wisp` в домашнем каталоге
- **AND** для Агента выбраны Скилл `spook-meeting`, модель `gpt-6.2-astra` и effort `medium`, программа Codex — `/opt/codex/bin/codex`
- **AND** программа уведомлений осталась `notify-send`

#### Scenario: Пути с «~» разворачиваются
- **GIVEN** в файле `wisp = "~/my-wisp"`, в разделе `[programs]` — `codex = "~/bin/codex"`, в разделе `[recognition]` — `model_dir = "~/models/gigaam"`
- **WHEN** Spook читает настройки
- **THEN** корень Wisp — `my-wisp`, программа Агента — `bin/codex`, папка модели — `models/gigaam`, все три в домашнем каталоге

#### Scenario: Служба запущена с другим файлом
- **WHEN** служба запущена командой `spook serve --settings <файл>`, а в файле указан `port`
- **THEN** служба слушает этот порт

#### Scenario: Путь из старых настроек Лекций
- **GIVEN** в файле есть `[lecture]` с прежней папкой и Скиллом Лекции, раздела `[meeting]` нет
- **WHEN** пользователь начинает и завершает Встречу с Репликой
- **THEN** Заметка и Агент используют настройки Встречи по умолчанию, прежняя папка не используется

#### Scenario: Прежние настройки Claude Code
- **GIVEN** указаны `[programs] claude`, модель Встречи `opus`, effort `medium` и прежняя папка Встреч
- **WHEN** служба читает настройки
- **THEN** используется программа Codex, модель `gpt-6.2-astra` и effort `high`. Для новых Заметок берётся корень `wisp`

#### Scenario: Пользовательская папка Скиллов
- **WHEN** указан путь `[agent] skills_dir`
- **THEN** Spook выбирает Скилл в этой папке, по умолчанию — в `~/.agents/skills`

### Requirement: Экран «Настройки» показывает текущие значения
Экран «Настройки» по адресу `/settings` SHALL показывать текущие значения полей Встречи — «Папка Wisp», «Скилл», «Модель Агента» и «Effort Агента», устройства Системного звука и Микрофона, «Минут тишины до автостопа» и путь к Словарю терминов. Настройки Лекций и остальные ключи файла на экране отсутствуют.

#### Scenario: Значения из файла настроек
- **GIVEN** в файле настроек `auto_stop_minutes = 1.5`, заданы корень Wisp и Скилл `my-meeting`, модель `gpt-6.2-sol` и effort `max`, также задан путь к Словарю терминов
- **WHEN** пользователь открывает экран «Настройки»
- **THEN** у Встречи видны заданные корень Wisp, Скилл, модель и effort
- **AND** время автостопа — `1.5`, у обоих Источников выбрано «по умолчанию», показан путь к Словарю терминов
- **AND** effort выбирается из списка `low`, `medium`, `high`, `xhigh`, `max`, `ultra`

### Requirement: Сохранение пишет поля экрана и не трогает остальные ключи
«Сохранить» SHALL записать в файл настроек все поля экрана и оставить без изменений остальные ключи и разделы файла, в том числе неизвестные Spook. После сохранения экран SHALL показать «Настройки сохранены. Действуют со следующей Сессии и следующего запуска Агента.» и новые значения.

#### Scenario: Сохранение рядом с ключами, которых нет на экране
- **GIVEN** в файле настроек есть `port`, раздел `[programs]`, `[recognition]` с `speech_threshold = 0.4`, прежний `[lecture]` и неизвестный раздел `[future]` с `key = "значение"`
- **WHEN** пользователь задаёт корень Wisp `<…>/Встречи с "кавычками"`, Скилл `my-meeting`, модель `gpt-6.2-sol`, effort `xhigh`, время автостопа `2,5`, путь к Словарю терминов `<…>/Словарь.md` и нажимает «Сохранить»
- **THEN** ключ `wisp` содержит новый путь, раздел `[meeting]` содержит выбранные Скилл, модель и effort, `auto_stop_minutes = 2.5`, `terms_dictionary` указывает на новый путь
- **AND** `port` и значения в `[programs]`, `[recognition]`, `[lecture]` и `[future]` остались прежними
- **AND** экран показывает «Настройки сохранены» и новые значения

### Requirement: Недопустимое значение отклоняется с причиной
Если хотя бы одно поле недопустимо, сохранение SHALL быть отклонено целиком с ответом 422: файл настроек остаётся прежним байт в байт, а экран показывает «Настройки не сохранены: исправьте отмеченные поля.», причину у каждого недопустимого поля и введённые значения. Папка Wisp и путь к Словарю терминов — полный путь; модель задана; effort — из списка; время автостопа — число больше нуля.

#### Scenario: Папка Заметок пуста или задана не полным путём
- **WHEN** пользователь сохраняет пустую папку Wisp или относительный путь `my-wisp`
- **THEN** у поля показано «Укажите папку Wisp» или причина о необходимости полного пути, файл настроек прежний

#### Scenario: Время автостопа — не число больше нуля
- **WHEN** пользователь сохраняет время автостопа `пять`, `0` или `-1`
- **THEN** у поля показано «Время автостопа — число минут больше нуля, а не «пять»» — с тем значением, которое введено
- **AND** файл настроек не изменился

#### Scenario: Неизвестный effort, пустая модель, пустой путь к Словарю терминов
- **WHEN** пользователь сохраняет effort Встречи `turbo`, пустую модель Встречи или пустой путь к Словарю терминов
- **THEN** у поля показано «Неизвестный effort «turbo»: допустимы low, medium, high, xhigh, max, ultra», «Укажите модель» или «Укажите путь к Словарю терминов»
- **AND** файл настроек не изменился, поле показывает введённое значение

#### Scenario: Допустимое поле рядом с недопустимым не сохраняется
- **GIVEN** сохранены модель Встречи `gpt-6.2-sol` и время автостопа `2.5`
- **WHEN** пользователь в браузере вводит модель Встречи `gpt-6.2-astra`, время автостопа `пять` и нажимает «Сохранить»
- **THEN** показаны «Время автостопа — число минут больше нуля, а не «пять»» и общее предупреждение, поле хранит `пять`
- **AND** файл настроек не изменился: после перезагрузки экран снова показывает `gpt-6.2-sol` и `2.5`

### Requirement: Изменения действуют со следующей Сессии и следующего запуска Агента
Корень Wisp, время автостопа, закреплённые устройства и параметры нарезки SHALL применяться со следующего «Старт», без перезапуска службы — сохранены ли они с экрана или записаны в файл. Идущая Сессия SHALL сохранять выбранный при «Старт» корень Wisp и своё время автостопа. Скилл, модель и effort SHALL браться из настроек в момент, когда Заметка встаёт в очередь Агента.

#### Scenario: Следующая Сессия идёт по новым настройкам
- **GIVEN** служба работает, Сессии нет
- **WHEN** пользователь сохраняет другой готовый корень Wisp, модель Встречи `gpt-6.2-astra`, effort `max`, время автостопа `2` и начинает Встречу 2026-11-06 в 14:02
- **THEN** рабочая HTML-Заметка находится в `.spook/` нового Wisp
- **AND** через 1 минуту 59 секунд после последней Реплики Сессия ещё идёт, через 2 минуты — завершена автостопом
- **AND** Агент вызван со Скиллом Встречи, моделью `gpt-6.2-astra` и effort `max`, рабочий каталог временный

#### Scenario: Сохранение во время Сессии
- **GIVEN** идёт Встреча, начатая 2026-11-06 в 14:02 с временем автостопа 5 минут
- **WHEN** пользователь сохраняет другой готовый корень Wisp, модель Встречи `gpt-6.2-astra` и время автостопа `10`
- **THEN** идущая Сессия завершается автостопом через 5 минут, её Заметка остаётся в прежнем Wisp
- **AND** Агент этой Заметки работает во временной папке с моделью `gpt-6.2-astra` и effort `high`
- **AND** следующая Встреча, начатая в 15:07, завершается автостопом через 10 минут, её Заметка опубликована в новом Wisp

#### Scenario: Время автостопа записано прямо в файл
- **GIVEN** служба работает, в файл настроек записано `auto_stop_minutes = 1.5`
- **WHEN** пользователь начинает Встречу и речи нет
- **THEN** через 89 секунд Сессия ещё идёт, через 90 секунд — завершена автостопом

### Requirement: Значения настроек Встречи и службы по умолчанию
Без файла настроек Spook SHALL использовать значения по умолчанию для Встречи, Источников, Агента, программ и распознавания. Чтение значений по умолчанию ничего на диске не создаёт.

#### Scenario: Общие ключи и настройки Встречи
- **WHEN** файла настроек нет
- **THEN** `port` — 8765, `auto_stop_minutes` — 5, `terms_dictionary` — `~/Documents/notes/работа/Словарь терминов.md`, `wisp` — `~/code/personal/wisp`
- **AND** в `[meeting]` значения `skill`, `model` и `effort` — `spook-meeting`, `gpt-6.2-astra` и `high`

#### Scenario: Источники, Агент и программы
- **WHEN** файла настроек нет
- **THEN** в `[sources]` ключи `system` и `mic` пусты — устройство по умолчанию
- **AND** в `[agent]`: `timeout_minutes` — 15, `wrapper` пуст
- **AND** в `[programs]`: `codex` — `~/.local/bin/codex`, `notify` — `notify-send`, `open` — `xdg-open`

#### Scenario: Распознавание
- **WHEN** файла настроек нет
- **THEN** в `[recognition]`: `max_utterance_seconds` — 20, `speech_threshold` — 0.5, `min_silence_duration_ms` — 500, `min_speech_duration_ms` — 250, `speech_pad_ms` — 100, `forced_cut_min_pause_ms` — 100
- **AND** `model_dir` — `$XDG_DATA_HOME/spook/models/gigaam-v3-e2e-rnnt`, `model_revision` — `322c3b29492673eb7d0b434bfa9dfb8653e34d02`, `quantization` — `int8`, `intra_op_threads` — 4, `inter_op_threads` — 1
