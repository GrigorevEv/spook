## Context

Раньше Claude Code изменял Заметку и переименовывал её командой службы. Теперь приложение получает готовый результат и само сохраняет его в Хранилище. Выбор и причины записаны в [ADR-0004](../../../docs/adr/0004-codex-meeting-agent.md).

## Decisions

- Вход Codex передаётся через стандартный ввод. В ответе обязательны строки `summary` и `topic`. Содержание Выжимки задаёт Скилл.
- Spook проверяет успешное завершение, формат и Выжимку до изменения Заметки. Существующая Тема сохраняется. Очередь, экран, Журнал Агента и уведомление следуют за окончательным именем.
- Запуск из отдельной временной папки использует закрытый профиль доступа. Служба читает выбранный Скилл и Словарь терминов. Для ссылок передаёт только названия доступных заметок и ссылки Вики.

## Risks / Trade-offs

Обновление CLI может изменить её возможности или вывод. Ошибка параметров, модели, доступа к подписке или структуры ответа видна в Журнале Агента. При сбое предыдущая Выжимка доступна для ручного перезапуска.
