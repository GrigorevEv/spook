## ADDED Requirements

### Requirement: Скилл Встречи применяется по выбору Spook
Spook SHALL выбрать Скилл по имени в настройках и передать Codex содержимое его SKILL.md. Модель, effort и профиль доступа задаёт служба.

#### Scenario: Другой Скилл
- **GIVEN** в настройках Встречи выбран Скилл пользователя
- **WHEN** очередь запускает Агента
- **THEN** вход содержит текст выбранного Скилла и данные одной Встречи

## MODIFIED Requirements

### Requirement: Выжимка пишется заново при каждом запуске
Скилл Встречи SHALL поручать Агенту писать Выжимку с нуля по переданному Транскрипту, включая ручной перезапуск.

#### Scenario: Повторный запуск для Заметки с Выжимкой
- **WHEN** пользователь подтверждает перезапуск Агента
- **THEN** Скилл поручает написать новую Выжимку по Транскрипту, предыдущая Выжимка отсутствует во входе

### Requirement: Выжимка Встречи — четыре раздела
Скилл `spook-meeting` SHALL поручать Агенту вернуть в поле `summary` Выжимку из четырёх разделов в таком порядке: «Суть» — 2–3 предложения, «Решения», «Задачи» — кто, что и срок, «Открытые вопросы». Все четыре раздела есть всегда; если сказать нечего — строка «Нет.». В Выжимку идёт только то, что прозвучало во Встрече.

#### Scenario: Разделы Выжимки Встречи
- **WHEN** Агент закончил работу по Скиллу `spook-meeting`
- **THEN** в поле `summary` ровно четыре раздела: `## Суть`, `## Решения`, `## Задачи`, `## Открытые вопросы`
- **AND** ответ соответствует схеме с полями `summary` и `topic`

#### Scenario: Кто взял задачу и к какому сроку
- **GIVEN** в Транскрипте пользователь говорит «я сделаю до пятницы», а исполнителя второй задачи и её срок никто не назвал
- **WHEN** Агент пишет раздел «Задачи»
- **THEN** первая задача записана как «**Я** — что сделать — до пятницы» с датой в скобках, отсчитанной от свойства `date`
- **AND** вторая — с «кто — не договорились» и «срок не назван»

### Requirement: Термины, имена и ссылки в Выжимке Встречи
Скилл SHALL поручать восстанавливать искажённые имена и термины по Словарю терминов, проверять написание публичного термина встроенным поиском Codex и обозначать неразборчивое. Запрос поиска содержит только публичный термин. Ссылки на заметки берутся из переданных Spook списков.

#### Scenario: Искажённый термин
- **GIVEN** Транскрипт содержит «кубер нетис», в Словаре терминов есть «Kubernetes»
- **WHEN** Агент пишет Выжимку
- **THEN** написание — «Kubernetes», ссылки на заметки Хранилища берутся как `[[Название]]`, Вики — готовыми ссылками

#### Scenario: Запрос для уточнения написания
- **WHEN** Словарь терминов не содержит публичный термин
- **THEN** Скилл разрешает поиск одного публичного термина без Реплик, имён коллег и внутренних сведений Встречи

#### Scenario: Списков заметок нет
- **WHEN** переданные списки заметок пусты
- **THEN** Выжимка не содержит ссылок на другие заметки

### Requirement: Скилл Встречи сохраняет свойства и Транскрипт Заметки
Скилл SHALL поручать вернуть только Выжимку и предложенную Тему. Свойства и Транскрипт сохраняет Spook.

#### Scenario: После работы Агента над Заметкой Встречи
- **WHEN** Агент закончил работу по Скиллу Встречи
- **THEN** ответ содержит Выжимку и Тему, свойства и Транскрипт остаются прежними

### Requirement: Скилл Встречи поручает Агенту придумать недостающую Тему
При пустой Теме Скилл SHALL поручать Агенту придумать Тему из 2–5 слов по-русски и вернуть её в `topic`.

#### Scenario: Заметка Встречи без Темы
- **WHEN** Агент получает Встречу с пустым полем `topic`
- **THEN** он предлагает Тему по разговору

#### Scenario: У Заметки уже есть Тема
- **WHEN** Тема во входе указана
- **THEN** Агент возвращает пустую строку `topic`

## REMOVED Requirements

### Requirement: Скилл Встречи вызывается явно с путём к Заметке

**Reason**: Прямой доступ Агента к Заметке заменён ответом Codex.
**Migration**: Spook передаёт выбранный Скилл и данные Встречи через стандартный ввод.

### Requirement: Шапка Скилла Встречи задаёт права Агента

**Reason**: Прямой доступ Агента к Заметке заменён ответом Codex.
**Migration**: Spook передаёт выбранный Скилл и данные Встречи через стандартный ввод.
