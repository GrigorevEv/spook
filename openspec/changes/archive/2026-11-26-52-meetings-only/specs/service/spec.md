## ADDED Requirements

### Requirement: Показ Встречи на подменах командой `spook demo`
Команда `spook demo` SHALL запустить ту же службу на подменах, чтобы показать Сессию без настоящего звука: текст появляется сам, по сценарию, а Заметки лежат во временной папке, которая удаляется при выходе. Порт задаётся ключом `--port`.

#### Scenario: Показ Встречи
- **GIVEN** запущен `spook demo --port <порт>`
- **WHEN** пользователь нажимает «Старт», дожидается Живого текста и нажимает «Стоп»
- **THEN** после «Старт» состояние — «идёт», в Живом тексте слова «Spook слушает звук на компьютере» и Реплики обоих Источников со временем по часам и говорящим
- **AND** после «Стоп» состояние — «нет Сессии», Заметка во временной папке содержит свойство `end` и Транскрипт Встречи

#### Scenario: Выход из показа
- **GIVEN** в показе проведена Встреча, её Заметка лежит во временной папке
- **WHEN** показ остановлен сигналом
- **THEN** команда завершается с кодом 0, Заметки больше нет

## MODIFIED Requirements

### Requirement: Команды принимаются только со своей страницы
Запрос с чужим `Origin` SHALL получать ответ 403 с текстом «Запрос с чужой страницы отклонён» и ничего не менять. Команда собственной страницы — открытой и как `localhost`, и как `127.0.0.1` — выполняется.

#### Scenario: «Старт» с чужой страницы
- **WHEN** приходит «Старт» Встречи с `Origin`, равным `http://attacker.example`, `null` или `http://localhost:1`
- **THEN** ответ — 403 «Запрос с чужой страницы отклонён»
- **AND** состояние остаётся «нет Сессии», папка Встреч не создана

#### Scenario: «Старт» со своей страницы
- **WHEN** приходит «Старт» Встречи с заголовками собственной страницы: `Origin: http://localhost:<порт>` и `Sec-Fetch-Site: same-origin`
- **THEN** Сессия начата, состояние — «идёт»

### Requirement: Поток событий открывается только своей странице
Запрос потока событий, у которого `Sec-Fetch-Site` — не `same-origin` и не `none`, SHALL получать ответ 403 с текстом «Запрос с чужой страницы отклонён»: чужая страница не читает Живой текст, даже если открыта на другом порту этого же компьютера.

#### Scenario: Поток событий с чужой страницы
- **WHEN** поток событий запрашивает страница другого сайта (`Sec-Fetch-Site: cross-site`), фрейм на другом сайте или страница `http://localhost:3000` (`Sec-Fetch-Site: same-site`)
- **THEN** каждый запрос получает 403 «Запрос с чужой страницы отклонён»

#### Scenario: Поток событий своей страницы
- **GIVEN** идёт Встреча
- **WHEN** поток событий запрашивает собственная страница (`Sec-Fetch-Site: same-origin`)
- **THEN** поток открыт, его первое событие — `state` с «идёт»

### Requirement: Вход не нужен
Интерфейс SHALL работать без входа и паролей. Запрос к своему адресу без браузерных заголовков `Origin` и `Sec-Fetch-Site` — так обращается к службе команда `spook topic` — SHALL приниматься.

#### Scenario: Команда из командной строки
- **GIVEN** служба запущена, в папке Встреч лежит завершённая Заметка без Темы
- **WHEN** выполняется `spook topic "<путь к Заметке>" "Репликация в Raft"`
- **THEN** служба принимает запрос без входа, команда печатает новый путь и завершается с кодом 0
