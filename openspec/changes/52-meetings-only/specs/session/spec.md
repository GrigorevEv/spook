## REMOVED Requirements

### Requirement: Вид Сессии выбирается при «Старт» и не меняется

**Reason**: Пользователь проводит только Встречи.
**Migration**: «Старт» можно вызвать без поля вида.

## ADDED Requirements

### Requirement: Каждая новая Сессия — Встреча

«Старт» SHALL начать Встречу с Системным звуком и Микрофоном. Явный вид `meeting` допустим для прежних клиентов. Любой другой вид SHALL отклоняться до захвата звука и создания Заметки.

#### Scenario: Старт без выбора вида

- **WHEN** пользователь нажимает «Старт» без поля вида
- **THEN** оба Источника захватываются, в папке Встреч появляется Заметка

#### Scenario: Прежний запрос Лекции

- **WHEN** клиент отправляет «Старт» с видом `lecture`
- **THEN** служба отклоняет запрос, старые Заметки остаются на месте
