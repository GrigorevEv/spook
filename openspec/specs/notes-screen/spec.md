# notes-screen Specification

## Purpose

Экран «Заметки» показывает Сессии по Заметкам в папке Встреч. С этого экрана пользователь открывает Заметку в Obsidian, запускает Агента заново и читает Журнал Агента.

## Requirements

### Requirement: Строка показывает начало, Тему, вид, длительность и состояние Выжимки
Каждая строка SHALL показывать: начало Сессии в виде `ГГГГ-ММ-ДД ЧЧ:ММ`; Тему из имени Заметки или «без Темы», если на месте Темы стоит «Встреча»; вид — «Встреча»; длительность — разницу свойств `end` и `start` в виде «N мин», а от часа — «H ч MM мин»; состояние Выжимки.

#### Scenario: Три Заметки с разной длительностью
- **GIVEN** Заметка Встречи `2026-11-06 14-02 Встреча.md` со свойствами `start: "14:02"`, `end: "14:47"` без Выжимки; Заметка Встречи `2026-11-05 10-00 Репликация в Raft.md` с `start: "10:00"`, `end: "11:05"` и Выжимкой; Заметка Встречи `2026-11-04 23-40 Встреча.md` с `start: "23:40"`, `end: "00:10"` без Выжимки
- **WHEN** пользователь открывает экран «Заметки»
- **THEN** первая строка — `2026-11-06 14:02`, «без Темы», «Встреча», «45 мин», «нет»
- **AND** вторая строка — `2026-11-05 10:00`, «Репликация в Raft», «Встреча», «1 ч 05 мин», «готово»
- **AND** третья строка — `2026-11-04 23:40`, «без Темы», «Встреча», «30 мин», «нет»

### Requirement: Состояние Выжимки в строке
Состояние Выжимки SHALL быть таким: если с запуска службы Агент работал над этой Заметкой — состояние его последнего запуска: «в очереди», «работает», «готово» или «ошибка» с причиной и предупреждением; иначе — «готово», когда над заголовком `## Транскрипт` есть Выжимка, и «нет», когда её нет.

#### Scenario: Ошибка Агента с причиной
- **GIVEN** Заметка Встречи `2026-11-06 14-02 Встреча.md` без Выжимки, длительность 45 минут
- **WHEN** Агент, запущенный для неё с экрана, завершился с ошибкой «Сценарий: Агент упал.»
- **THEN** строка показывает `2026-11-06 14:02`, «без Темы», «Встреча», «45 мин», «ошибка Сценарий: Агент упал.»

#### Scenario: Выжимка есть, а запусков с начала работы службы не было
- **GIVEN** Заметка Встречи `2026-11-05 10-00 Репликация в Raft.md` с Выжимкой и Заметка `2026-11-04 23-40 Встреча.md` без Выжимки; Агент после запуска службы над ними не работал
- **WHEN** пользователь открывает экран «Заметки»
- **THEN** первая строка показывает «готово», вторая — «нет»

### Requirement: Строка Заметки, которая ещё в работе
Строка Заметки идущей Сессии SHALL показывать «Сессия идёт» и не предлагать запуск Агента. Строка Заметки, которая в очереди или в работе у Агента, SHALL обновляться сама каждые 2 секунды и не предлагать запуск, пока Агент не закончил.

#### Scenario: Заметка идущей Сессии
- **GIVEN** идёт Встреча с Заметкой `2026-11-06 14-02 Встреча.md`
- **WHEN** пользователь открывает экран «Заметки»
- **THEN** строка этой Заметки показывает «Сессия идёт» и не предлагает «Запустить Агента»
- **AND** запуск Агента для этой Заметки отклоняется с причиной «Сессия с этой Заметкой ещё идёт», Агент не вызывается

#### Scenario: Строка следит за работой Агента
- **GIVEN** Агент работает над Заметкой Встречи
- **WHEN** пользователь смотрит на экран «Заметки»
- **THEN** строка показывает «работает» и не предлагает запуск
- **AND** когда Агент закончил, строка сама сменилась на «готово» и снова предлагает «Перезапустить Агента»

### Requirement: Запуск Агента для Заметки с выбором модели и effort
Строка Заметки, которая не занята Агентом и не принадлежит идущей Сессии, SHALL предлагать запуск Агента с выбором модели — `gpt-6.2-astra`, `gpt-6.2-sol` и модель из настроек — и effort — `low`, `medium`, `high`, `xhigh`, `max`, `ultra`; заранее SHALL быть выбраны модель и effort из настроек Встречи. Действие называется «Запустить Агента» для Заметки без Выжимки и «Перезапустить Агента» для Заметки с Выжимкой. Выбранные модель и effort действуют только на этот запуск.

#### Scenario: Заметка без Выжимки
- **GIVEN** Заметка Встречи `2026-11-06 14-02 Встреча.md` без Выжимки, настройки Встречи по умолчанию
- **WHEN** пользователь открывает её строку
- **THEN** строка предлагает «Запустить Агента» без предупреждения, выбраны модель `gpt-6.2-astra` и effort `high`
- **AND** после «Запустить» Агент вызван со Скиллом и Транскриптом Встречи, моделью `gpt-6.2-astra` и effort `high`

#### Scenario: Заранее выбраны значения из настроек
- **GIVEN** в настройках Встречи модель `gpt-6.2-sol` и effort `medium`
- **WHEN** пользователь открывает строку Заметки Встречи с Выжимкой
- **THEN** строка предлагает «Перезапустить Агента», выбраны `gpt-6.2-sol` и `medium`

### Requirement: Перезапуск предупреждает, что Выжимка будет написана заново
Для Заметки с Выжимкой форма запуска SHALL показывать предупреждение «Выжимка будет написана заново: прежняя Выжимка заменится новой.» и требовать поставить флажок «понимаю, запустить заново». Запуск без подтверждения SHALL быть отклонён с причиной «Выжимка будет написана заново: прежняя Выжимка заменится новой. Подтвердите перезапуск», Агент при этом не запускается.

#### Scenario: Перезапуск без подтверждения
- **GIVEN** Заметка Встречи `2026-11-05 10-00 Репликация в Raft.md` с Выжимкой
- **WHEN** приходит команда запустить Агента с моделью `gpt-6.2-astra` и effort `low` без подтверждения
- **THEN** команда отклонена с причиной, которая содержит «Выжимка будет написана заново»
- **AND** Агент не вызван

#### Scenario: Перезапуск с подтверждением
- **GIVEN** та же Заметка
- **WHEN** пользователь ставит флажок «понимаю, запустить заново», выбирает модель `gpt-6.2-astra`, effort `low` и нажимает «Запустить»
- **THEN** Агент вызван со Скиллом Встречи, моделью `gpt-6.2-astra` и effort `low`, рабочая папка временная

#### Scenario: Браузер не отправляет форму без флажка
- **GIVEN** в браузере открыт экран «Заметки», у Заметки Встречи есть Выжимка
- **WHEN** пользователь раскрывает «Перезапустить Агента» и нажимает «Запустить», не поставив флажок
- **THEN** предупреждение видно, новый запуск Агента не начат
- **AND** когда флажок поставлен и «Запустить» нажато снова, строка показывает «работает», затем «готово»

### Requirement: Модель и effort запуска — только простые имена
Запуск Агента с экрана SHALL быть отклонён, если модель или effort — не одно простое имя: латинские буквы, цифры и знаки `.`, `_`, `:`, `-`, `[`, `]`, не длиннее 80 знаков, первый знак — буква или цифра. Агент при отказе не запускается.

#### Scenario: Значение, похожее на флаг командной строки
- **WHEN** приходит команда запустить Агента с моделью `--dangerously-skip-permissions` и effort `high`
- **THEN** команда отклонена, Агент не вызван

#### Scenario: Значение с пробелом и пустое значение
- **WHEN** приходит команда запустить Агента с моделью `gpt-6.2-astra` и effort `high --verbose`, а затем — с пустой моделью и effort `high`
- **THEN** обе команды отклонены, Агент не вызван

### Requirement: Журнал Агента открывается из списка
Строка SHALL иметь ссылку «Журнал», когда для Заметки есть Журнал Агента, — то есть у каждой Заметки, над которой Агент когда-либо работал, в том числе до перезапуска службы. Ссылка SHALL открывать Журнал Агента целиком как текст.

#### Scenario: Журнал Агента есть у каждой Заметки, над которой работал Агент
- **GIVEN** над Заметкой `2026-11-06 14-02 Встреча` Агент работал только что; для Заметки `2026-11-05 10-00 Репликация в Raft` остался Журнал Агента с текстом «Журнал прошлой работы службы.»; над Заметкой `2026-11-04 09-00 Планёрка` Агент не работал
- **WHEN** пользователь открывает экран «Заметки»
- **THEN** у первых двух строк есть ссылка «Журнал», у третьей её нет
- **AND** по ссылке второй строки открывается текст «Журнал прошлой работы службы.»

### Requirement: Список Сессий строится по Заметкам в папке Встреч
Экран «Заметки» по адресу `/notes` SHALL показывать по строке на каждую Заметку Встречи из папки, заданной в настройках на момент открытия. Список каждый раз строится по файлам `.md` прямо в папке Встреч с именами вида `ГГГГ-ММ-ДД ЧЧ-ММ <остальное>`. Старые Заметки с тегом `лекция` SHALL пропускаться даже в папке Встреч.

#### Scenario: Заметки Встреч и посторонние файлы
- **GIVEN** в папке Встреч есть `2026-11-06 14-02 Встреча.md`, `2026-11-05 10-00 Планёрка.md`, `Словарь терминов.md` и `Планы на год.md`, а в прежней папке Лекций лежит старая Заметка
- **WHEN** пользователь открывает экран «Заметки»
- **THEN** в списке две строки — для Встречи без Темы и для «Планёрки»

#### Scenario: Удалённая Заметка исчезает из списка
- **GIVEN** в списке Заметки с Темами «Репликация в Raft» и «Планёрка»
- **WHEN** Заметка «2026-11-06 14-02 Планёрка» удалена из папки и экран открыт заново
- **THEN** в списке осталась одна строка с Темой «Репликация в Raft»

#### Scenario: Заметок ещё нет
- **WHEN** пользователь открывает экран «Заметки», а в папке Встреч нет ни одной Заметки Сессии
- **THEN** вместо списка показано «Сессий пока нет: Заметки появятся здесь после первой Сессии.»

#### Scenario: Оба пути прежде указывали на одну папку
- **GIVEN** в папке Встреч лежат Заметка с `tags: [встреча]` и старая Заметка с `tags: [лекция]`, у обеих имена Сессий
- **WHEN** пользователь открывает экран «Заметки»
- **THEN** в списке только Заметка Встречи, старая Заметка сохранила имя и содержимое

### Requirement: Заметки Встреч идут от новых к старым
Строки SHALL идти от новых Сессий к старым по дате и времени начала.

#### Scenario: Встречи за несколько дней
- **GIVEN** Встречи начались 2026-11-06 в 14:02, 2026-11-05 в 10:00 и 2026-11-04 в 23:40
- **WHEN** пользователь открывает экран «Заметки»
- **THEN** строки идут в порядке `2026-11-06 14:02`, `2026-11-05 10:00`, `2026-11-04 23:40`

### Requirement: «Открыть в Obsidian» открывает Заметку Встречи
У каждой строки SHALL быть действие «Открыть в Obsidian». Spook SHALL сам вызвать системное средство открытия (настройка `[programs] open`, по умолчанию `xdg-open`) с одним аргументом — адресом `obsidian://open?path=<полный путь к Заметке>`, где путь закодирован для URL целиком, вместе с «/», — и ответить «Открываю в Obsidian: <имя Заметки>».

#### Scenario: Заметка Встречи открывается в Obsidian
- **GIVEN** в папке Встреч `<…>/meetings` лежит Заметка `2026-11-06 14-02 Встреча.md`
- **WHEN** пользователь нажимает «Открыть в Obsidian» в её строке
- **THEN** средство открытия вызвано один раз с одним аргументом
- **AND** аргумент начинается с `obsidian://open?path=%2F` и заканчивается на `%2Fmeetings%2F2026-11-06%2014-02%20%D0%92%D1%81%D1%82%D1%80%D0%B5%D1%87%D0%B0.md`

### Requirement: Действия принимают только Заметки из папки Встреч
«Открыть в Obsidian» и запуск Агента SHALL приниматься только для Заметки Встречи, лежащей прямо в папке Встреч. В остальных случаях служба SHALL отклонить команду с причиной. Внешние программы при отказе не вызываются. Действие «Открыть страницу Вики» отсутствует.

#### Scenario: Путь не полный
- **WHEN** приходит любая из двух команд с путём `2026-11-06 14-02 Встреча.md` без папки или с пустым путём
- **THEN** команда отклонена с причиной «Нужен полный путь к Заметке: <путь>»
- **AND** средство открытия и Агент не вызваны

#### Scenario: Файл в папке Встреч — не Заметка Сессии
- **WHEN** приходит любая из двух команд для `<папка Встреч>/Словарь терминов.md`
- **THEN** команда отклонена с причиной «Это не Заметка Сессии: <путь>»
- **AND** средство открытия и Агент не вызваны

#### Scenario: Заметка вне папки Встреч
- **GIVEN** вне папки Встреч лежит `<…>/чужое/2026-11-06 14-02 Чужая.md`
- **WHEN** приходит любая из двух команд с этим путём или с путём `<папка Встреч>/../чужое/2026-11-06 14-02 Чужая.md`
- **THEN** команда отклонена с причиной «Заметка вне папки Встреч: <путь>»
- **AND** средство открытия и Агент не вызваны

#### Scenario: Заметки нет или на её месте ссылка наружу
- **GIVEN** в папке Встреч нет `2026-11-06 16-00 Нет такой.md`, а `2026-11-06 15-00 Ссылка наружу.md` — ссылка на файл вне папки Встреч
- **WHEN** приходит любая из двух команд для одного из этих путей
- **THEN** команда отклонена с причиной «Заметки нет: <имя Заметки>»
- **AND** средство открытия и Агент не вызваны

#### Scenario: Команда со старой Заметкой Лекции
- **GIVEN** в папке Встреч осталась старая Заметка с тегом `лекция`
- **WHEN** клиент пытается открыть её в Obsidian через Spook или запустить для неё Агента
- **THEN** служба отклоняет запрос, средство открытия и Агент не вызываются, старая Заметка остаётся по прежнему пути с прежним содержимым

#### Scenario: Прежняя команда открытия страницы Вики
- **WHEN** клиент отправляет `POST /notes/wiki` для Заметки
- **THEN** служба возвращает 404, программа Вики и средство открытия не вызываются
