# agent Specification

## Purpose

После Встречи Агент пишет Выжимку в Заметку. Spook запускает Claude Code без диалога по Скиллу Встречи (ADR-0003), передаёт Агенту Словарь терминов и сведения для ссылок, принимает Тему и охраняет Транскрипт. Служба ведёт очередь запусков, сохраняет Журнал Агента и показывает исход каждого запуска.

## Requirements

### Requirement: Заметка завершённой Сессии встаёт в очередь Агента
Когда Сессия с хотя бы одной Репликой завершена — по «Стоп», автостопу или после долгого перерыва в работе службы, — её Заметка SHALL один раз встать в очередь Агента под окончательным именем. Сессия без Реплик Агента не запускает.

#### Scenario: После «Стоп» Агент запущен один раз
- **GIVEN** идёт Встреча, начатая 2026-11-06 в 14:02, распознана Реплика «Реплика.»
- **WHEN** пользователь нажимает «Стоп»
- **THEN** Агент вызван ровно один раз — для Заметки `2026-11-06 14-02 Встреча.md`

#### Scenario: Агент получает окончательное имя Заметки
- **GIVEN** идёт Встреча, во время Сессии введена Тема «Репликация в Raft»
- **WHEN** пользователь нажимает «Стоп»
- **THEN** Агент вызван для `<папка Встреч>/2026-11-06 14-02 Репликация в Raft.md`, и Журнал Агента назван по этому имени

#### Scenario: Сессия без Реплик
- **GIVEN** идёт Встреча, звук распознан пустым текстом
- **WHEN** пользователь нажимает «Стоп»
- **THEN** Агент и программа уведомлений не вызваны, блок Агента на экране пуст

### Requirement: Агенты работают по одному
Агенты SHALL работать по одному, в порядке очереди: Заметка, ждущая своей очереди, показывает «в очереди», та, над которой идёт работа, — «работает». Автоматических повторов нет: неудачный запуск остаётся ошибкой, пока пользователь сам не запустит Агента заново.

#### Scenario: Вторая Сессия ждёт Агента первой
- **GIVEN** Встреча, начатая в 14:02, завершена, Агент работает над её Заметкой
- **WHEN** пользователь проводит вторую Встречу, начатую в 15:02, и нажимает «Стоп»
- **THEN** экран показывает «работает» для `2026-11-06 14-02 Встреча` и «в очереди» для `2026-11-06 15-02 Встреча`
- **AND** Агент вызван сначала для первой Заметки, потом для второй, обе доходят до «готово»

### Requirement: Обёртка запуска и ограничение времени
Запуск SHALL ограничиваться временем из настройки `[agent] timeout_minutes` (по умолчанию 15 минут): Агент, работающий дольше, останавливается, и исход — ошибка «Превышено время: Агент работал дольше N мин». Команда из настройки `[agent] wrapper` SHALL ставиться перед программой Агента; `{timeout}` в ней заменяется на лимит в секундах.

#### Scenario: Агент работает дольше лимита
- **GIVEN** в настройках `timeout_minutes = 0.02`, Агент завис
- **WHEN** лимит времени истёк
- **THEN** Агент остановлен, исход — «ошибка» с причиной «Превышено время», та же причина записана в Журнал Агента

#### Scenario: Запуск через обёртку
- **GIVEN** в настройках `timeout_minutes = 2` и `wrapper = "env SPOOK_UNIT_LIMIT={timeout}"`
- **WHEN** Агент запущен
- **THEN** Журнал Агента начинается с `$ env SPOOK_UNIT_LIMIT=120 <программа Агента> -p `

### Requirement: Исход запуска — «готово» или «ошибка»
Исход SHALL быть «готово», только если запуск завершился успешно и над заголовком `## Транскрипт` появилась Выжимка, отличная от прежней. Иначе исход — «ошибка» с причиной: «Агент завершился, но Выжимки в Заметке нет», «Агент завершился, но Выжимка не обновлена» или сообщение самого запуска. При ошибке Заметка остаётся с Транскриптом.

#### Scenario: Агент написал Выжимку
- **GIVEN** Встреча с Репликой «Реплика.» завершена в 14:02
- **WHEN** Агент вписал над Транскриптом «## Суть» с текстом «Про тесты.» и завершился успешно
- **THEN** экран показывает «готово» без ошибки
- **AND** Заметка: свойства `date: 2026-11-06`, `start: "14:02"`, `end: "14:02"`, `tags: [встреча]`, затем Выжимка, `## Транскрипт` и `**14:02 Собеседники:** Реплика.`

#### Scenario: Агент упал
- **WHEN** запуск завершился с кодом 1 и строкой «Сценарий: Агент упал.» в потоке ошибок
- **THEN** экран показывает «ошибка» и причину «Сценарий: Агент упал.»

#### Scenario: Агент завершился без Выжимки
- **WHEN** запуск завершился успешно, а над Транскриптом ничего не написано
- **THEN** экран показывает «ошибка» и причину «Агент завершился, но Выжимки в Заметке нет»

#### Scenario: Повторный запуск не обновил Выжимку
- **GIVEN** в Заметке `2026-11-05 10-00 Репликация в Raft.md` есть Выжимка «## Суть» с текстом «Про Raft.»
- **WHEN** Агент, запущенный для неё заново, завершился успешно и ничего не изменил
- **THEN** исход — «ошибка» с причиной «Агент завершился, но Выжимка не обновлена», в Заметке прежний текст «Про Raft.»

### Requirement: Причины ошибок распознаются по выводу запуска
Spook SHALL распознавать по выводу запуска и показывать причину ошибки: блокировку хуком — «Запуск заблокирован хуком (проверьте VPN)», даже при коде возврата 0; отсутствие сети — «Нет сети»; исчерпанный лимит подписки — «Исчерпан лимит подписки». В остальных случаях причина — сообщение запуска: первая строка его результата или последняя строка потока ошибок.

#### Scenario: Запуск заблокирован хуком
- **WHEN** запуск завершился с кодом 0, а его вывод сообщает о блокировке хуком `UserPromptSubmit`
- **THEN** исход — «ошибка» с причиной «Запуск заблокирован хуком (проверьте VPN)»
- **AND** Журнал Агента хранит вывод запуска как есть

#### Scenario: Нет сети
- **WHEN** запуск завершился с кодом 1 и ошибкой соединения `connection_failed`
- **THEN** исход — «ошибка» с причиной «Нет сети», Журнал Агента заканчивается строкой «Код возврата: 1. Выжимка: ошибка — Нет сети»

#### Scenario: Исчерпан лимит подписки
- **WHEN** запуск завершился с кодом 1, а его вывод сообщает об отклонении по лимиту (`rate_limit`)
- **THEN** исход — «ошибка» с причиной «Исчерпан лимит подписки»

#### Scenario: Нераспознанная ошибка API
- **WHEN** запуск завершился с кодом 1 и результатом «API Error: 500 Internal server error — …»
- **THEN** причина ошибки содержит «API Error: 500 Internal server error»

#### Scenario: Запуск сорвался до вывода
- **WHEN** запуск завершился с кодом 1 без вывода, а в потоке ошибок «Error: When using --print, --output-format=stream-json requires --verbose»
- **THEN** причина ошибки — эта строка

### Requirement: Отказы в правах
Отказы в правах, о которых сообщил запуск, SHALL показываться как «Отказ в правах: <инструмент> <цель>; …». Если Выжимка при этом написана, исход — «готово» с этим предупреждением; если нет — «ошибка», и отказы названы её причиной.

#### Scenario: Выжимка написана, но были отказы
- **WHEN** запуск завершился успешно с Выжимкой и сообщил об отказах инструменту Read в чтении файла `outside.md` и инструменту Bash в команде `cat` для него
- **THEN** исход — «готово» с предупреждением «Отказ в правах: Read <путь>/outside.md; Bash cat <путь>/outside.md» на экране и в Журнале Агента

#### Scenario: Отказы и нет Выжимки
- **WHEN** запуск завершился успешно без Выжимки и сообщил о тех же отказах
- **THEN** исход — «ошибка», её причина начинается с «Отказ в правах: Read», а не с «Выжимки в Заметке нет»

### Requirement: Предупреждение о модели и effort в шапке Скилла
Если в шапке Скилла — пользовательского или проектного — указаны `model` или `effort`, Spook SHALL предупредить на экране и в Журнале Агента: «В шапке Скилла <Скилл> указаны <ключи> — они перебивают модель и effort из настроек Spook.» Упоминание `model` в тексте Скилла ниже шапки предупреждения не даёт.

#### Scenario: Проектный Скилл с моделью и effort в шапке
- **GIVEN** в шапке `<папка Встреч>/.claude/skills/spook-meeting/SKILL.md` записаны `model: sonnet` и `effort: high`
- **WHEN** Агент отработал для Заметки Встречи
- **THEN** экран и Журнал Агента содержат «В шапке Скилла spook-meeting указаны model, effort — они перебивают модель и effort из настроек Spook.»

#### Scenario: Пользовательский Скилл с моделью в шапке
- **GIVEN** в шапке пользовательского Скилла `spook-meeting` записана `model`
- **WHEN** Агент отработал для Заметки Встречи
- **THEN** экран содержит «В шапке Скилла spook-meeting указаны model — они перебивают»

#### Scenario: Модель упомянута только в тексте Скилла
- **GIVEN** в тексте Скилла ниже шапки есть строка «model: так в тексте Скилла можно писать.»
- **WHEN** Агент отработал
- **THEN** предупреждения о шапке Скилла нет

### Requirement: Журнал Агента открывается из интерфейса
Ссылка «Журнал» SHALL открывать Журнал Агента целиком как текст. Запрос Журнала Агента для неизвестной Заметки SHALL получать ответ 404, а имя, ведущее за пределы каталога, где лежат Журналы Агента, не обслуживается.

#### Scenario: Журнал Агента по ссылке с экрана «Сессия»
- **GIVEN** Агент отработал для Заметки `2026-11-06 14-02 Встреча`
- **WHEN** пользователь открывает ссылку «Журнал» в блоке Агента
- **THEN** ответ — текст (`text/plain`), равный Журналу Агента

#### Scenario: Журнала Агента нет и путь наружу
- **GIVEN** рядом с каталогом, где лежат Журналы Агента, лежит файл `secret.log` с текстом «не журнал»
- **WHEN** запрошены Журналы Агента для Заметок с именами `нет такой` и `../secret`
- **THEN** оба ответа — 404, текста «не журнал» в ответе нет

### Requirement: Уведомление о конце работы Агента
Когда Агент закончил, Spook SHALL отправить системное уведомление — вызвать программу из настройки `[programs] notify` (по умолчанию `notify-send`) с заголовком и текстом: «Выжимка готова» и имя Заметки либо «Ошибка Агента» и «<имя Заметки>: <причина>». Неотправленное уведомление SHALL записываться в журнал службы и не менять исход.

#### Scenario: Выжимка готова
- **WHEN** Агент написал Выжимку для Заметки `2026-11-06 14-02 Встреча`
- **THEN** программа уведомлений вызвана с аргументами «Выжимка готова» и «2026-11-06 14-02 Встреча»

#### Scenario: Ошибка Агента
- **WHEN** Агент упал с причиной «Сценарий: Агент упал.»
- **THEN** программа уведомлений вызвана с аргументами «Ошибка Агента» и «2026-11-06 14-02 Встреча: Сценарий: Агент упал.»

#### Scenario: Уведомление не отправилось
- **GIVEN** программа уведомлений завершается с ошибкой «служба уведомлений недоступна»
- **WHEN** Агент написал Выжимку
- **THEN** в журнале службы предупреждение, которое называет «Выжимка готова» и «служба уведомлений недоступна»; исход остаётся «готово»

### Requirement: Журнал службы о запусках Агента
В журнал службы Spook SHALL записывать начало и исход каждого запуска Агента: «Агент запущен: <Заметка> — <Скилл>, <модель>, <effort>» и «Агент закончил: <Заметка> — <исход>», для ошибки — с причиной.

#### Scenario: Неудачный запуск в журнале службы
- **GIVEN** в настройках Встречи модель `sonnet` и effort `medium`
- **WHEN** Агент для Заметки `2026-11-06 14-02 Встреча` упал
- **THEN** в журнале службы «Агент запущен: 2026-11-06 14-02 Встреча — spook-meeting, sonnet, medium» и «Агент закончил: 2026-11-06 14-02 Встреча — ошибка: Сценарий: Агент упал.»

### Requirement: Очередь Агента переживает перезапуск службы
После перезапуска службы Заметки Встреч, ждавшие в очереди, SHALL запуститься в прежнем порядке. Прерванный запуск для Встречи SHALL стать ошибкой «Агент прерван перезапуском службы» с уведомлением без повторного запуска. Транскрипт его Заметки проверяется и восстанавливается, уже написанная Выжимка остаётся. Служба SHALL пропускать прежние задачи Лекций, сохраняя их Заметки без изменений.

#### Scenario: Перезапуск службы во время работы Агента
- **GIVEN** Агент работает над Заметкой `2026-11-06 14-02 Встреча`: написал Выжимку «Про тесты.» и переписал Транскрипт; Заметка `2026-11-06 15-02 Встреча` ждёт в очереди
- **WHEN** служба перезапущена
- **THEN** для первой Заметки показаны «Агент прерван перезапуском службы» и «Агент изменил Транскрипт — возвращён исходный.», в ней Выжимка и исходный абзац `**14:02 Собеседники:** Первая встреча.`; заново Агент для неё не вызван
- **AND** Агент вызван для второй Заметки и дошёл до «готово»
- **AND** уведомления: «Ошибка Агента» с текстом «2026-11-06 14-02 Встреча: Агент прерван перезапуском службы», затем «Выжимка готова» с текстом «2026-11-06 15-02 Встреча»

#### Scenario: В сохранённой очереди есть прежние задачи Лекций
- **GIVEN** до обновления в очереди остались Заметки Встреч и задачи `lecture`, одна из которых была в работе
- **WHEN** служба запускается после обновления
- **THEN** она восстанавливает задачи Встреч в прежнем порядке
- **AND** она не запускает Агента для старых Заметок Лекций и не переписывает их по сохранённой копии Транскрипта

### Requirement: Охрана Транскрипта
Перед запуском Агента Spook SHALL запомнить Заметку, а после запуска сверить всё от заголовка `## Транскрипт` до конца. Изменённый Транскрипт SHALL быть возвращён к исходному с сохранением Выжимки; об этом сообщают экран и Журнал Агента: «Агент изменил Транскрипт — возвращён исходный.» Агент, не тронувший Транскрипт, сообщений не вызывает.

#### Scenario: Агент не тронул Транскрипт
- **WHEN** Агент написал Выжимку и не менял Транскрипт
- **THEN** на экране нет сообщений о Транскрипте, в Журнале Агента нет строки «Охрана Транскрипта»

#### Scenario: Агент переписал Транскрипт
- **GIVEN** в Заметке Встречи Транскрипт из одного абзаца
- **WHEN** Агент написал Выжимку и заменил Транскрипт на «Транскрипт переписан Агентом.»
- **THEN** в Заметке Выжимка Агента и исходный Транскрипт, исход — «готово»
- **AND** экран показывает «Агент изменил Транскрипт — возвращён исходный.», Журнал Агента — «Охрана Транскрипта: Агент изменил Транскрипт — возвращён исходный.» перед строкой «Код возврата: 0. Выжимка: готово»

### Requirement: Стёртые заголовок и Заметка восстанавливаются
Если Агент стёр заголовок `## Транскрипт`, Spook SHALL вернуть заголовок с Транскриптом под ним и сообщить «Агент стёр заголовок «Транскрипт» — Транскрипт возвращён на место.» Если Агент стёр Заметку, Spook SHALL записать её заново со свойствами и Транскриптом, сообщить «Агент стёр Заметку — восстановлены свойства и Транскрипт.», а запуск считается ошибкой.

#### Scenario: Агент стёр заголовок «Транскрипт»
- **WHEN** Агент написал Выжимку и удалил строку `## Транскрипт`
- **THEN** в Заметке Выжимка, заголовок и Транскрипт под ним, исход — «готово»
- **AND** Журнал Агента содержит «Охрана Транскрипта: Агент стёр заголовок «Транскрипт» — Транскрипт возвращён на место.»

#### Scenario: Агент удалил Заметку
- **WHEN** Агент удалил Заметку
- **THEN** Заметка записана заново такой, какой была до запуска: со свойствами и Транскриптом
- **AND** исход — «ошибка» с причиной «Агент завершился, но Выжимки в Заметке нет», экран и Журнал Агента сообщают «Агент стёр Заметку — восстановлены свойства и Транскрипт.»

### Requirement: Тема от Агента — команда `spook topic`
Команда `spook topic <Заметка> <Тема…>` SHALL дать завершённой Заметке без Темы имя с этой Темой, напечатать новый путь и завершиться с кодом 0. Тема очищается и обрезается до 80 знаков так же, как введённая пользователем; слова Темы можно не брать в кавычки; при совпадении имён добавляется ` (2)`.

#### Scenario: Агент называет Заметку без Темы
- **GIVEN** Встреча завершена, её Заметка — `2026-11-06 14-02 Встреча.md`
- **WHEN** выполняется `spook topic "<папка Встреч>/2026-11-06 14-02 Встреча.md" "Репликация в Raft"`
- **THEN** команда печатает `<папка Встреч>/2026-11-06 14-02 Репликация в Raft.md`, поток ошибок пуст, код 0
- **AND** в папке Встреч одна Заметка — с новым именем, экран показывает новое имя вместо старого

#### Scenario: Тема от Агента очищается
- **WHEN** Тема передана как ` Raft:<табуляция>"репликация" <журнала>/логов? #1 *|\ `
- **THEN** Заметка названа `2026-11-06 14-02 Raft репликация журнала логов 1.md`

#### Scenario: Длинная Тема отдельными словами
- **WHEN** Тема передана отдельными словами: Распределённые системы — консенсус, репликация журнала, снимки состояния, перевыборы лидера и членство в кластере
- **THEN** Заметка названа `2026-11-06 14-02 Распределённые системы — консенсус, репликация журнала, снимки состояния, перевы.md`

#### Scenario: Тема повторяет имя другой Заметки
- **GIVEN** в папке Встреч есть `2026-11-06 14-02 Raft.md` и `2026-11-06 14-02 Встреча.md`
- **WHEN** для второй Заметки выполняется `spook topic` с Темой «Raft»
- **THEN** команда печатает путь к `2026-11-06 14-02 Raft (2).md`, обе Заметки на месте

### Requirement: Запуск следует за Заметкой, которую переименовал Агент
Когда Агент во время работы дал Заметке Тему, очередь, охрана Транскрипта, Журнал Агента, исход и уведомление SHALL перейти на новое имя: «готово» показывается под новым именем, а Заметка под старым именем не восстанавливается.

#### Scenario: Агент сообщил Тему и написал Выжимку по новому пути
- **GIVEN** Встреча с Заметкой `2026-11-06 14-02 Встреча.md` завершена
- **WHEN** Агент выполняет `spook topic` с Темой «Репликация в Raft» и пишет Выжимку в переименованную Заметку
- **THEN** экран показывает «готово» для `2026-11-06 14-02 Репликация в Raft`
- **AND** Журнал Агента — `2026-11-06 14-02 Репликация в Raft.log`, уведомление — «Выжимка готова» с текстом «2026-11-06 14-02 Репликация в Raft»

#### Scenario: Охрана Транскрипта не возвращает старое имя
- **GIVEN** Встреча с Репликой «Лидер рассылает записи журнала.» завершена
- **WHEN** Агент дал Заметке Тему «Репликация в Raft», написал Выжимку и не менял Транскрипт
- **THEN** в папке Встреч только `2026-11-06 14-02 Репликация в Raft.md` с Выжимкой и прежним Транскриптом
- **AND** предупреждений на экране и строки «Охрана Транскрипта» в Журнале Агента нет

#### Scenario: Заметка осталась в папке, которую сменили во время Сессии
- **GIVEN** во время Встречи в настройках сохранена другая папка Встреч
- **WHEN** Сессия завершена и Агент даёт её Заметке Тему «Репликация в Raft»
- **THEN** в прежней папке Встреч лежит `2026-11-06 14-02 Репликация в Raft.md`, исход — «готово»

### Requirement: Заготовка Словаря терминов
Если файла Словаря терминов по пути из настроек нет, перед запуском Агента Встречи Spook SHALL создать заготовку с заголовком «# Словарь терминов» и пояснением, как его вести. Существующий Словарь терминов SHALL оставаться нетронутым.

#### Scenario: Словаря терминов нет
- **GIVEN** файла Словаря терминов нет
- **WHEN** Агент запущен для Заметки Встречи
- **THEN** файл создан, он начинается со строки «# Словарь терминов» и объясняет, что Агент сверяется с ним

#### Scenario: Словарь терминов уже есть
- **GIVEN** в Словаре терминов одна строка «- Kubernetes — кубер»
- **WHEN** Агент запущен для Заметки Встречи
- **THEN** содержимое файла не изменилось

### Requirement: Повторный запуск Агента для Заметки
Пользователь SHALL иметь возможность запустить Агента для Заметки заново — с моделью и effort, выбранными на этот запуск: Заметка снова встаёт в очередь, Выжимка пишется заново. Заметка, которая уже в очереди или в работе, второй раз не ставится: отказ «Агент для этой Заметки уже в очереди» или «Агент для этой Заметки уже работает». На экране «Сессия» Заметка показана один раз, с исходом последнего запуска.

#### Scenario: Заметка уже в работе
- **GIVEN** Агент работает над Заметкой
- **WHEN** приходит ещё одна команда запустить Агента для неё
- **THEN** команда отклонена с причиной, которая содержит «уже работает»; всего Агент вызван один раз

#### Scenario: После перезапусков Заметка показана один раз
- **GIVEN** для Заметки Агент отработал с исходом «готово»
- **WHEN** пользователь запускает Агента заново, и тот не обновляет Выжимку
- **THEN** блок Агента на экране «Сессия» показывает эту Заметку один раз — с «ошибка» и причиной «Агент завершился, но Выжимка не обновлена»

### Requirement: Агент Встречи запускается одним вызовом Claude Code
Spook SHALL запускать Агента одним вызовом программы Claude Code без диалога: `-p "/<Скилл> <путь к Заметке>"`, с `--model` и `--effort` из настроек Встречи, выводом `stream-json` и режимом прав `default` без запросов подтверждения. Программа берётся из настройки `[programs] claude` и вызывается напрямую, а не через оболочку пользователя.

#### Scenario: Аргументы запуска для Встречи
- **GIVEN** в настройках Встречи Скилл `spook-meeting`, модель `sonnet`, effort `medium`
- **WHEN** Встреча с Заметкой `2026-11-06 14-02 Встреча.md` завершена
- **THEN** программа Агента вызвана с аргументами `-p "/spook-meeting <папка Встреч>/2026-11-06 14-02 Встреча.md"`, `--model sonnet --effort medium`, `--output-format stream-json --verbose --include-hook-events`, `--permission-mode default --permission-prompts none` и `--disallowedTools <правила>`

### Requirement: Агент работает в папке Заметки Встречи
Агент SHALL работать в папке, где лежит Заметка Встречи.

#### Scenario: Встреча — папка Встреч
- **WHEN** Агент запущен для Заметки Встречи
- **THEN** его рабочий каталог — папка Встреч

### Requirement: Защита настроек Claude Code и файлов Вики при запуске Агента Встречи
При любом Скилле Spook SHALL запрещать Агенту флагом `--disallowedTools` правку настроек Claude Code в папках `.claude` рабочего каталога, папки Встреч и Вики. Правка папок `_tools` и `_templates` Вики также SHALL быть запрещена.

#### Scenario: Запреты для Встречи
- **WHEN** Агент запущен для Заметки в папке Встреч
- **THEN** после `--disallowedTools` идут правила `Edit(/<папка Встреч>/**/.claude/**)`, `Edit(/<Вики>/**/.claude/**)`, `Edit(/<Вики>/_tools/**)` и `Edit(/<Вики>/_templates/**)`, в которых каждая папка задана полным путём

### Requirement: Для Заметки Встречи ведётся Журнал Агента
Весь вывод запуска SHALL сохраняться в Журнал Агента в каталоге состояния по пути `agent/meeting/<имя Заметки>.log`. Каждый запуск начинается с командной строки и рабочего каталога и заканчивается строкой «Код возврата: N. Выжимка: <исход>». Повторный запуск той же Заметки SHALL дописываться в тот же Журнал Агента.

#### Scenario: Журнал Агента после неудачного запуска
- **GIVEN** настройки Агента по умолчанию, Встреча с Заметкой `2026-11-06 14-02 Встреча.md` завершена
- **WHEN** Агент упал с «Сценарий: Агент упал.» в потоке ошибок
- **THEN** Журнал Агента `<каталог состояния>/agent/meeting/2026-11-06 14-02 Встреча.log` начинается строкой `$ <программа Агента> -p '/spook-meeting <путь к Заметке>' --model opus --effort high …` и строкой `(рабочий каталог: <папка Встреч>)`
- **AND** за выводом запуска идут `--- stderr ---`, «Сценарий: Агент упал.» и «Код возврата: 1. Выжимка: ошибка — Сценарий: Агент упал.»
- **AND** Журнал Агента не появился в папке Встреч

#### Scenario: Повторный запуск дописывается в тот же Журнал Агента
- **GIVEN** для Заметки Агент отработал с моделью `sonnet` и исходом «готово»
- **WHEN** пользователь запускает Агента заново с моделью `haiku`, и тот ничего не пишет
- **THEN** в Журнале Агента по порядку: запуск с `--model sonnet`, «Выжимка: готово», запуск с `--model haiku`, «Выжимка: ошибка»

### Requirement: Отказы команды `spook topic` для Заметок Встреч
`spook topic` SHALL отказать — причина в потоке ошибок, код завершения 1, Заметка не тронута, — когда Сессия с этой Заметкой ещё идёт, у Заметки уже есть Тема, Заметка лежит вне папки Встреч, Заметки нет или Тема пуста.

#### Scenario: Сессия с этой Заметкой ещё идёт
- **GIVEN** идёт Встреча с Заметкой `2026-11-06 14-02 Встреча.md`
- **WHEN** для неё выполняется `spook topic` с Темой «Репликация в Raft»
- **THEN** причина отказа — «Сессия с этой Заметкой ещё идёт», вывод пуст, код 1, имя Заметки прежнее

#### Scenario: У Заметки уже есть Тема
- **GIVEN** завершённая Заметка `2026-11-06 14-02 Raft.md`
- **WHEN** для неё выполняется `spook topic` с Темой «Репликация в Raft»
- **THEN** причина отказа — «У Заметки уже есть Тема: 2026-11-06 14-02 Raft.md»

#### Scenario: Заметка вне папки Встреч
- **GIVEN** вне папки Встреч лежит `<…>/notes/2026-11-06 14-02 Встреча.md`
- **WHEN** для неё выполняется `spook topic`
- **THEN** причина отказа — «Заметка вне папки Встреч: <…>/notes/2026-11-06 14-02 Встреча.md»

#### Scenario: Заметки нет и Тема пуста
- **WHEN** `spook topic` выполняется для несуществующей `<папка Встреч>/2026-11-06 15-02 Встреча.md`, а затем для существующей Заметки с Темой из пробелов и знаков `?*"\`
- **THEN** причины отказа — «Заметки нет: 2026-11-06 15-02 Встреча.md» и «Тема пуста»; в папке Встреч по-прежнему `2026-11-06 14-02 Встреча.md`

#### Scenario: Ссылка в папке Встреч ведёт наружу
- **GIVEN** `<папка Встреч>/2026-11-06 14-02 Встреча.md` — ссылка на файл вне папки Встреч
- **WHEN** для неё выполняется `spook topic`
- **THEN** причина отказа — «Заметки нет: 2026-11-06 14-02 Встреча.md», ссылка не переименована

#### Scenario: Старая Заметка Лекции в папке Встреч
- **GIVEN** в папке Встреч осталась старая Заметка без Темы с тегом `лекция`
- **WHEN** для неё выполняется `spook topic` с Темой «Планёрка»
- **THEN** команда отклонена, имя и содержимое старой Заметки сохранены

### Requirement: Словарь терминов и списки заметок для Агента Встречи
Агенту Встречи Spook SHALL передать сведения для ссылок: путь к Словарю терминов, имена заметок рабочего Хранилища — без содержимого и без самой Заметки — и заметки Вики с готовыми ссылками. Сведения передаются файлом через `--append-system-prompt-file`; скрытые папки пропускаются.

#### Scenario: Имена заметок без содержимого
- **GIVEN** в рабочем Хранилище лежат `работа/2026-10-01 10-00 Планирование релиза.md`, `личное/Пароли.md` с текстом «пароль: hunter2», `.obsidian/Служебное.md` и `работа/схема.png`; в Вики — `Raft.md` и `SCST/SCST.md`
- **WHEN** Агент запущен для Заметки Встречи `2026-11-06 14-02 Встреча`
- **THEN** в сведениях есть имена «2026-10-01 10-00 Планирование релиза» и «Пароли», ссылки `[Raft](obsidian://open?vault=wiki&file=Raft)` и `[SCST](obsidian://open?vault=wiki&file=SCST%2FSCST)` и путь к Словарю терминов
- **AND** в сведениях нет «Служебное», «схема», текста «hunter2» и имени самой Заметки
