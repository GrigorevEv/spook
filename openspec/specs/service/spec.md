# service Specification

## Purpose

Служба Spook — фоновая служба пользователя с интерфейсом во вкладке браузера. Она слушает только этот компьютер, работает без входа и паролей и пускает к интерфейсу только собственную страницу, чтобы ни другое устройство в сети, ни посторонний сайт в том же браузере не могли управлять Spook и читать Живой текст. Сюда же относится показ на подменах — `spook demo`.

## Requirements

### Requirement: Служба слушает только этот компьютер
Команда `spook serve` SHALL запустить службу, которая слушает только адрес `127.0.0.1` на порту из настройки `port` (по умолчанию 8765), и SHALL NOT принимать соединения на сетевом адресе машины.

#### Scenario: Соединение по адресу 127.0.0.1
- **GIVEN** служба запущена с портом из настроек
- **WHEN** клиент соединяется с `127.0.0.1` и с `127.0.0.2` на этом порту
- **THEN** первое соединение принято, второе отклонено

#### Scenario: Сетевой адрес машины
- **GIVEN** у машины есть сетевой адрес
- **WHEN** клиент соединяется с этим адресом на порту службы
- **THEN** соединение отклонено

### Requirement: Запрос к чужому адресу отклоняется
Запрос, в котором `Host` — не `localhost:<порт>` и не `127.0.0.1:<порт>`, SHALL получать ответ 403 с текстом «Запрос к чужому адресу отклонён».

#### Scenario: Чужой Host
- **WHEN** приходит запрос страницы `/` с `Host`, равным `attacker.example:<порт>`, `localhost:1` или `127.0.0.1` без порта
- **THEN** ответ — 403 «Запрос к чужому адресу отклонён»

#### Scenario: Свой адрес
- **WHEN** приходит запрос страницы `/` с `Host`, равным `localhost:<порт>` или `127.0.0.1:<порт>`
- **THEN** ответ — 200, экран «Сессия»

### Requirement: Команды принимаются только со своей страницы
Запрос с чужим `Origin` SHALL получать ответ 403 с текстом «Запрос с чужой страницы отклонён» и ничего не менять. Команда собственной страницы — открытой и как `localhost`, и как `127.0.0.1` — выполняется.

#### Scenario: «Старт» с чужой страницы
- **WHEN** приходит «Старт» Встречи с `Origin`, равным `http://attacker.example`, `null` или `http://localhost:1`
- **THEN** ответ — 403 «Запрос с чужой страницы отклонён»
- **AND** состояние остаётся «нет Сессии», папка Встреч не создана

#### Scenario: «Старт» со своей страницы
- **WHEN** приходит «Старт» Встречи с заголовками собственной страницы: `Origin: http://localhost:<порт>` и `Sec-Fetch-Site: same-origin`
- **THEN** Сессия начата, состояние — «идёт»

### Requirement: Поток событий открывается только своей странице
Запрос потока событий, у которого `Sec-Fetch-Site` — не `same-origin` и не `none`, SHALL получать ответ 403 с текстом «Запрос с чужой страницы отклонён»: чужая страница не читает Живой текст, даже если открыта на другом порту этого же компьютера.

#### Scenario: Поток событий с чужой страницы
- **WHEN** поток событий запрашивает страница другого сайта (`Sec-Fetch-Site: cross-site`), фрейм на другом сайте или страница `http://localhost:3000` (`Sec-Fetch-Site: same-site`)
- **THEN** каждый запрос получает 403 «Запрос с чужой страницы отклонён»

#### Scenario: Поток событий своей страницы
- **GIVEN** идёт Встреча
- **WHEN** поток событий запрашивает собственная страница (`Sec-Fetch-Site: same-origin`)
- **THEN** поток открыт, его первое событие — `state` с «идёт»

### Requirement: Открыть страницу по ссылке можно, встроить в чужой сайт — нельзя
Переход на страницу Spook по ссылке с другого сайта SHALL обслуживаться, а загрузка страницы во фрейм другого сайта SHALL получать ответ 403 с текстом «Запрос с чужой страницы отклонён».

#### Scenario: Переход по ссылке с другого сайта
- **WHEN** браузер запрашивает `/` как переход верхнего уровня с другого сайта (`Sec-Fetch-Site: cross-site`, `Sec-Fetch-Mode: navigate`, `Sec-Fetch-Dest: document`)
- **THEN** ответ — 200, экран «Сессия»

#### Scenario: Страница во фрейме чужого сайта
- **WHEN** браузер запрашивает `/` для фрейма на другом сайте (`Sec-Fetch-Dest: iframe`)
- **THEN** ответ — 403 «Запрос с чужой страницы отклонён»

### Requirement: Вход не нужен
Интерфейс SHALL работать без входа и паролей. Запрос к своему адресу без браузерных заголовков `Origin` и `Sec-Fetch-Site` — так обращается к службе команда `spook topic` — SHALL приниматься.

#### Scenario: Команда из командной строки
- **GIVEN** служба запущена, в папке Встреч лежит завершённая Заметка без Темы
- **WHEN** выполняется `spook topic "<путь к Заметке>" "Репликация в Raft"`
- **THEN** служба принимает запрос без входа, команда печатает новый путь и завершается с кодом 0

### Requirement: Служба останавливается сразу и тихо
По сигналу остановки служба SHALL закрыть открытые потоки событий и завершиться с кодом 0 без трассировки ошибки — даже когда открыты вкладки.

#### Scenario: Остановка при двух открытых вкладках
- **GIVEN** служба запущена командой `spook serve`, открыты два потока событий
- **WHEN** служба получает сигнал SIGTERM
- **THEN** она завершается с кодом 0 быстрее чем за полторы секунды
- **AND** в её выводе нет «Traceback»

### Requirement: Служба запускается и без модели распознавания
Без скачанной модели распознавания `spook serve` SHALL запуститься и записать в журнал службы предупреждение «Модель распознавания не скачана в <папка>: выполните `spook prepare`».

#### Scenario: Папки модели нет
- **GIVEN** в настройках `[recognition] model_dir` указывает на несуществующую папку
- **WHEN** выполняется `spook serve`
- **THEN** служба слушает свой порт и отвечает на запросы

### Requirement: Показ Встречи на подменах командой `spook demo`
Команда `spook demo` SHALL запустить ту же службу на подменах, чтобы показать Сессию без настоящего звука: текст появляется сам, по сценарию, а Заметки лежат во временной папке, которая удаляется при выходе. Порт задаётся ключом `--port`.

#### Scenario: Показ Встречи
- **GIVEN** запущен `spook demo --port <порт>`
- **WHEN** пользователь нажимает «Старт», дожидается Живого текста и нажимает «Стоп»
- **THEN** после «Старт» состояние — «идёт», в Живом тексте слова «Spook слушает звук на компьютере» и Реплики обоих Источников со временем по часам и говорящим
- **AND** после «Стоп» состояние — «нет Сессии», Заметка во временной папке содержит свойство `end` и Транскрипт Встречи

#### Scenario: Выход из показа
- **GIVEN** в показе проведена Встреча, её Заметка лежит во временной папке
- **WHEN** показ остановлен сигналом
- **THEN** команда завершается с кодом 0, Заметки больше нет
