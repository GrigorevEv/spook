# settings Specification

## Purpose

Настройки Spook — файл в домашнем каталоге пользователя, вне Хранилищ, и экран «Настройки», который правит часть его ключей: папки Заметок, Скилл, модель и effort Агента для каждого вида Сессии, устройства Источников, время автостопа и путь к Словарю терминов. Остальные ключи пользователь правит прямо в файле.

## Requirements

### Requirement: Файл настроек
Spook SHALL читать настройки из файла TOML `$XDG_CONFIG_HOME/spook/settings.toml`, а без `XDG_CONFIG_HOME` — из `~/.config/spook/settings.toml`; команды `spook serve`, `spook prepare` и `spook topic` принимают другой файл через `--settings`. Ключ, которого в файле нет, SHALL сохранять значение по умолчанию; `~` в путях SHALL разворачиваться в домашний каталог.

#### Scenario: Частичный файл меняет только указанные ключи
- **GIVEN** в файле настроек `port = 9000`, `auto_stop_minutes = 7`, в разделе `[lecture]` — `folder = "~/lectures"` и `effort = "medium"`, в разделе `[programs]` — `claude = "/opt/claude/bin/claude"`
- **WHEN** Spook читает настройки
- **THEN** порт — 9000, время автостопа — 7 минут, папка Лекций — `lectures` в домашнем каталоге
- **AND** у Лекции Скилл `spook-lecture`, модель `opus`, effort `medium`
- **AND** папка Встреч и программа уведомлений `notify-send` остались по умолчанию

#### Scenario: Пути с «~» разворачиваются
- **GIVEN** в файле `wiki = "~/vault/wiki"`, в разделе `[programs]` — `claude = "~/bin/claude"`, в разделе `[recognition]` — `model_dir = "~/models/gigaam"`
- **WHEN** Spook читает настройки
- **THEN** корень Вики — `vault/wiki`, программа Агента — `bin/claude`, папка модели — `models/gigaam`, все три в домашнем каталоге

#### Scenario: Служба запущена с другим файлом
- **WHEN** служба запущена командой `spook serve --settings <файл>`, а в файле указан `port`
- **THEN** служба слушает этот порт

### Requirement: Значения по умолчанию
Без файла настроек Spook SHALL работать со значениями по умолчанию и ничего не создавать на диске: общие ключи, ключи каждого вида Сессии, Источников, Агента, программ и распознавания перечислены в сценариях.

#### Scenario: Общие ключи и виды Сессии
- **WHEN** файла настроек нет
- **THEN** `port` — 8765, `auto_stop_minutes` — 5, `terms_dictionary` — `~/Documents/notes/работа/Словарь терминов.md`, `wiki` — `~/learn/wiki`
- **AND** в `[meeting]`: `folder` — `~/Documents/notes/работа`, `skill` — `spook-meeting`, `model` — `opus`, `effort` — `high`
- **AND** в `[lecture]`: `folder` — `~/learn/wiki/lectures`, `skill` — `spook-lecture`, `model` — `opus`, `effort` — `high`

#### Scenario: Источники, Агент и программы
- **WHEN** файла настроек нет
- **THEN** в `[sources]` ключи `system` и `mic` пусты — устройство по умолчанию
- **AND** в `[agent]`: `timeout_minutes` — 15, `wrapper` пуст
- **AND** в `[programs]`: `claude` — `~/.local/bin/claude`, `notify` — `notify-send`, `open` — `xdg-open`, `wiki` — `python3 ~/learn/wiki/_tools/wiki_html.py`

#### Scenario: Распознавание
- **WHEN** файла настроек нет
- **THEN** в `[recognition]`: `max_utterance_seconds` — 20, `speech_threshold` — 0.5, `min_silence_duration_ms` — 500, `min_speech_duration_ms` — 250, `speech_pad_ms` — 100, `forced_cut_min_pause_ms` — 100
- **AND** `model_dir` — `$XDG_DATA_HOME/spook/models/gigaam-v3-e2e-rnnt`, `model_revision` — `322c3b29492673eb7d0b434bfa9dfb8653e34d02`, `quantization` — `int8`, `intra_op_threads` — 4, `inter_op_threads` — 1

### Requirement: Экран «Настройки» показывает текущие значения
Экран «Настройки» по адресу `/settings` SHALL показывать значения из файла настроек на момент открытия: для Встречи и для Лекции — «Папка Заметок», «Скилл», «Модель Агента», «Effort Агента»; для Системного звука и Микрофона — устройство; «Минут тишины до автостопа»; путь к Словарю терминов. Остальные ключи файла на экране не показываются.

#### Scenario: Значения из файла настроек
- **GIVEN** в файле настроек `auto_stop_minutes = 1.5`, у Лекции — Скилл `my-lecture`, модель `sonnet`, effort `max`; остальное — папки Встреч и Лекций и путь к Словарю терминов
- **WHEN** пользователь открывает экран «Настройки»
- **THEN** у Встречи показаны её папка, Скилл `spook-meeting`, модель `opus`, effort `high`
- **AND** у Лекции — её папка, Скилл `my-lecture`, модель `sonnet`, effort `max`
- **AND** время автостопа — `1.5`, у обоих Источников выбрано «по умолчанию», показан путь к Словарю терминов
- **AND** effort выбирается из списка `low`, `medium`, `high`, `xhigh`, `max`

### Requirement: Экран напоминает, что права Агента заданы в Скилле
Рядом с папкой Заметок каждого вида Сессии экран «Настройки» SHALL напоминать: «Права Агента здесь не задаются: они записаны отдельно, в шапке Скилла.»

#### Scenario: Напоминание у каждого вида Сессии
- **WHEN** пользователь открывает экран «Настройки»
- **THEN** напоминание про шапку Скилла показано дважды — у Встречи и у Лекции

### Requirement: Устройства Источников для закрепления
Для каждого Источника экран «Настройки» SHALL предлагать «по умолчанию» и устройства, которые система сейчас называет для этого Источника: для Системного звука — устройства вывода, для Микрофона — устройства ввода. Выбор устройства закрепляет его за Источником, «по умолчанию» снимает закрепление. Закреплённое устройство, которого сейчас нет, SHALL оставаться выбранным, с припиской «(сейчас нет)».

#### Scenario: Список устройств каждого Источника
- **GIVEN** система называет устройства вывода «Наушники USB» и «HDMI» и устройство ввода «Микрофон USB», ничего не закреплено
- **WHEN** пользователь открывает экран «Настройки»
- **THEN** для Системного звука предложены «по умолчанию», «Наушники USB» и «HDMI», выбрано «по умолчанию»
- **AND** для Микрофона предложены «по умолчанию» и «Микрофон USB»

#### Scenario: Закрепление и возврат к устройству по умолчанию
- **GIVEN** устройство «HDMI» известно системе как `alsa_output.hdmi`, «Микрофон USB» — как `alsa_input.usb`
- **WHEN** пользователь выбирает для Системного звука «HDMI», для Микрофона — «Микрофон USB» и сохраняет
- **THEN** в файле настроек в разделе `[sources]` записано `system = "alsa_output.hdmi"` и `mic = "alsa_input.usb"`, и следующая Лекция захватывает Системный звук с закреплённого устройства
- **AND** когда пользователь снова выбирает «по умолчанию» и сохраняет, в файле `system = ""`, и следующая Лекция захватывает устройство по умолчанию

#### Scenario: Закреплённого устройства сейчас нет
- **GIVEN** за Системным звуком закреплено `alsa_output.usb`, а система его сейчас не называет
- **WHEN** пользователь открывает экран «Настройки»
- **THEN** для Системного звука выбрано «alsa_output.usb (сейчас нет)»

#### Scenario: Виртуальные устройства PipeWire
- **GIVEN** в PipeWire созданы виртуальное устройство вывода «Spook test output» и виртуальное устройство ввода «Spook test microphone»
- **WHEN** пользователь открывает экран «Настройки»
- **THEN** «Spook test output» предложено только для Системного звука, «Spook test microphone» — только для Микрофона

### Requirement: Сохранение пишет поля экрана и не трогает остальные ключи
«Сохранить» SHALL записать в файл настроек все поля экрана и оставить без изменений остальные ключи и разделы файла, в том числе неизвестные Spook. После сохранения экран SHALL показать «Настройки сохранены. Действуют со следующей Сессии и следующего запуска Агента.» и новые значения.

#### Scenario: Сохранение рядом с ключами, которых нет на экране
- **GIVEN** в файле настроек есть `port`, раздел `[programs]`, `[recognition]` с `speech_threshold = 0.4` и неизвестный раздел `[future]` с `key = "значение"`
- **WHEN** пользователь задаёт для Встречи папку `<…>/Встречи с "кавычками"`, Скилл `my-meeting`, модель `sonnet`, effort `xhigh`, для Лекции — effort `low`, время автостопа `2,5`, путь к Словарю терминов `<…>/Словарь.md` и нажимает «Сохранить»
- **THEN** в файле раздел `[meeting]` содержит эти папку, Скилл, модель и effort; в `[lecture]` — `effort = "low"` и прежняя папка; `auto_stop_minutes = 2.5`; `terms_dictionary` — новый путь
- **AND** `port`, `[programs]`, `[recognition]` и `[future]` остались прежними
- **AND** экран показывает «Настройки сохранены» и новые значения

### Requirement: Недопустимое значение отклоняется с причиной
Если хотя бы одно поле недопустимо, сохранение SHALL быть отклонено целиком с ответом 422: файл настроек остаётся прежним байт в байт, а экран показывает «Настройки не сохранены: исправьте отмеченные поля.», причину у каждого недопустимого поля и введённые значения. Папка Заметок и путь к Словарю терминов — полный путь; модель задана; effort — из списка; время автостопа — число больше нуля.

#### Scenario: Папка Заметок пуста или задана не полным путём
- **WHEN** пользователь сохраняет пустую папку Встреч или папку Лекций `lectures`
- **THEN** у поля показано «Укажите папку Заметок вида «Встреча»» или «Нужен полный путь (от «/» или «~»), а не «lectures»»
- **AND** файл настроек не изменился

#### Scenario: Время автостопа — не число больше нуля
- **WHEN** пользователь сохраняет время автостопа `пять`, `0` или `-1`
- **THEN** у поля показано «Время автостопа — число минут больше нуля, а не «пять»» — с тем значением, которое введено
- **AND** файл настроек не изменился

#### Scenario: Неизвестный effort, пустая модель, пустой путь к Словарю терминов
- **WHEN** пользователь сохраняет effort Лекции `turbo`, пустую модель Встречи или пустой путь к Словарю терминов
- **THEN** у поля показано «Неизвестный effort «turbo»: допустимы low, medium, high, xhigh, max», «Укажите модель» или «Укажите путь к Словарю терминов»
- **AND** файл настроек не изменился, поле показывает введённое значение

#### Scenario: Допустимое поле рядом с недопустимым не сохраняется
- **GIVEN** сохранены модель Встречи `sonnet` и время автостопа `2.5`
- **WHEN** пользователь в браузере вводит модель Встречи `haiku`, время автостопа `пять` и нажимает «Сохранить»
- **THEN** показаны «Время автостопа — число минут больше нуля, а не «пять»» и общее предупреждение, поле хранит `пять`
- **AND** файл настроек не изменился: после перезагрузки экран снова показывает `sonnet` и `2.5`

### Requirement: Изменения действуют со следующей Сессии и следующего запуска Агента
Папка Заметок, время автостопа, закреплённые устройства и параметры нарезки SHALL применяться со следующего «Старт», без перезапуска службы — сохранены ли они с экрана или записаны в файл. Идущая Сессия SHALL сохранять папку своей Заметки и своё время автостопа. Скилл, модель и effort SHALL браться из настроек в момент, когда Заметка встаёт в очередь Агента.

#### Scenario: Следующая Сессия идёт по новым настройкам
- **GIVEN** служба работает, Сессии нет
- **WHEN** пользователь сохраняет папку Встреч `<…>/Новые встречи`, модель Встречи `haiku`, effort `max`, время автостопа `2` и начинает Встречу 2026-11-06 в 14:02
- **THEN** Заметка создана как `<…>/Новые встречи/2026-11-06 14-02 Встреча.md`
- **AND** через 1 минуту 59 секунд после последней Реплики Сессия ещё идёт, через 2 минуты — завершена автостопом
- **AND** Агент вызван с `/spook-meeting <путь к Заметке>`, моделью `haiku` и effort `max`, рабочий каталог — новая папка

#### Scenario: Сохранение во время Сессии
- **GIVEN** идёт Встреча, начатая 2026-11-06 в 14:02 с временем автостопа 5 минут
- **WHEN** пользователь сохраняет папку Встреч `<…>/Новые встречи`, модель Встречи `haiku` и время автостопа `10`
- **THEN** идущая Сессия завершается автостопом через 5 минут, её Заметка остаётся в прежней папке Встреч
- **AND** Агент этой Заметки работает в её папке с моделью `haiku` и effort `high`
- **AND** следующая Встреча, начатая в 15:07, завершается автостопом через 10 минут, её Заметка — `<…>/Новые встречи/2026-11-06 15-07 Встреча.md`

#### Scenario: Время автостопа записано прямо в файл
- **GIVEN** служба работает, в файл настроек записано `auto_stop_minutes = 1.5`
- **WHEN** пользователь начинает Лекцию и речи нет
- **THEN** через 89 секунд Сессия ещё идёт, через 90 секунд — завершена автостопом
