# audio-capture Specification

## Purpose

Захват звука Сессии: какие Источники слушает Spook, с каких устройств идёт захват, что происходит, когда устройство сменилось или пропало, и что об Источниках видит пользователь — название устройства и уровень сигнала. Звук живёт только в памяти (ADR-0001).

## Requirements

### Requirement: Источники по виду Сессии
Встреча SHALL захватывать Системный звук и Микрофон, Лекция — только Системный звук: звук Микрофона во время Лекции в Транскрипт не попадает.

#### Scenario: Встреча слушает оба Источника
- **WHEN** пользователь начинает Встречу
- **THEN** захватываются Системный звук и Микрофон, и экран «Сессия» называет оба Источника

#### Scenario: Лекция слушает только Системный звук
- **GIVEN** идёт Лекция
- **WHEN** 20 секунд речи звучат и в Микрофоне, и в Системном звуке, а в Системном звуке распознано «Слова лектора.»
- **THEN** распознан только Системный звук: в Транскрипте один абзац `**0:00:00** Слова лектора.`
- **AND** папка Встреч не создана

### Requirement: Источник без закрепления слушает устройство по умолчанию
Источник без закреплённого устройства SHALL захватываться через PipeWire с устройства по умолчанию: Системный звук — всё, что воспроизводит устройство вывода по умолчанию, Микрофон — с устройства ввода по умолчанию.

#### Scenario: Системный звук — с устройства вывода по умолчанию
- **GIVEN** устройство вывода по умолчанию — «Колонки», закреплений нет
- **WHEN** пользователь начинает Лекцию
- **THEN** экран «Сессия» показывает для Системного звука устройство «Колонки»

#### Scenario: Системный звук — то, что воспроизводит устройство вывода
- **GIVEN** в PipeWire создано виртуальное устройство вывода «Spook test output», Лекция захватывает его
- **WHEN** в это устройство 2 секунды воспроизводится тон амплитудой 0,1
- **THEN** до тона уровень Системного звука `rms` меньше 0,001
- **AND** во время тона `rms` около 0,0707, `peak` около 0,1

#### Scenario: Устройства PipeWire по умолчанию
- **GIVEN** настоящий PipeWire, закреплений нет
- **WHEN** Spook выбирает устройства Источников
- **THEN** устройство Системного звука — устройство вывода PipeWire по умолчанию, устройство Микрофона — устройство ввода PipeWire по умолчанию

### Requirement: Захват следует за сменой устройства по умолчанию
Когда устройство по умолчанию сменилось, захват незакреплённого Источника SHALL перейти на новое устройство без остановки Сессии. Текущая Реплика Источника закрывается в момент смены, в Транскрипте остаётся Отметка `<время> <Источник> переключён на «<устройство>»`, экран показывает новое название. Предупреждения при этом нет.

#### Scenario: Переключение на наушники посреди Лекции
- **GIVEN** идёт Лекция с устройства «образцы», за 25 секунд прозвучало «Начало.» и «Хвост.»
- **WHEN** устройством вывода по умолчанию становятся «Наушники USB» и звучит «После смены.»
- **THEN** Сессия идёт, экран показывает устройство «Наушники USB»
- **AND** в Транскрипте `**0:00:00** Начало. Хвост.`, Отметка `*0:00:25 Системный звук переключён на «Наушники USB»*` и абзац `**0:00:25** После смены.`
- **AND** предупреждения на экране нет

### Requirement: Закреплённое устройство
Источник, за которым в настройках закреплено устройство, SHALL захватываться с этого устройства и SHALL NOT следовать за сменой устройства по умолчанию.

#### Scenario: Закреплённое устройство вместо устройства по умолчанию
- **GIVEN** за Системным звуком закреплено «Виртуальное устройство», устройство по умолчанию — «образцы»
- **WHEN** пользователь начинает Лекцию, а устройством по умолчанию становятся «Наушники USB»
- **THEN** экран показывает для Системного звука «Виртуальное устройство», «Наушники USB» на экране нет
- **AND** в Транскрипте нет Отметки о смене устройства

#### Scenario: Закреплённый захват не замечает смену умолчания
- **GIVEN** за Системным звуком закреплены «Колонки» (`alsa_output.speakers`), идёт Лекция
- **WHEN** устройством по умолчанию становятся «Наушники USB», а потом снова «Колонки»
- **THEN** захват всё время идёт с `alsa_output.speakers`, «Наушники USB» на экране не появляются

### Requirement: Пропажа устройства не прерывает Сессию
Когда устройство Источника пропало, Сессия SHALL продолжиться: захват переходит на устройство по умолчанию, в Транскрипте остаётся Отметка `<время> <Источник>: устройство «<старое>» пропало, захват продолжается с «<новое>»`, на экране «Сессия» — предупреждение с тем же текстом без времени. Если пропало закреплённое устройство, до конца Сессии захват следует за устройством по умолчанию.

#### Scenario: Пропало устройство Системного звука
- **GIVEN** идёт Лекция с устройства «образцы», за 20 секунд прозвучало «До пропажи.»
- **WHEN** устройство «образцы» пропадает, устройством по умолчанию становятся «Динамики ноутбука» и звучит «После пропажи.»
- **THEN** Сессия идёт, экран показывает устройство «Динамики ноутбука»
- **AND** в Транскрипте `**0:00:00** До пропажи.`, Отметка `*0:00:20 Системный звук: устройство «образцы» пропало, захват продолжается с «Динамики ноутбука»*` и абзац `**0:00:20** После пропажи.`
- **AND** на экране предупреждение «Системный звук: устройство «образцы» пропало, захват продолжается с «Динамики ноутбука»»

#### Scenario: Пропало закреплённое устройство
- **GIVEN** за Системным звуком закреплено «Виртуальное устройство», Лекция идёт полторы минуты
- **WHEN** «Виртуальное устройство» пропадает
- **THEN** в Транскрипте Отметка `*0:01:30 Системный звук: устройство «Виртуальное устройство» пропало, захват продолжается с «образцы»*`, на экране предупреждение с тем же текстом
- **AND** когда устройством по умолчанию становятся «Наушники USB», захват переходит на них с Отметкой «Системный звук переключён на «Наушники USB»»

#### Scenario: Во Встрече пропал Микрофон
- **GIVEN** идёт Встреча, начатая в 14:02; за Микрофоном закреплена «Гарнитура»; в Транскрипте `**14:02 Собеседники:** До пропажи.`
- **WHEN** в 14:03 «Гарнитура» пропадает и пользователь говорит «После пропажи.»
- **THEN** в Транскрипте Отметка `*14:03 Микрофон: устройство «Гарнитура» пропало, захват продолжается с «образцы»*` и абзац `**14:03 Я:** После пропажи.`
- **AND** на экране предупреждение «Микрофон: устройство «Гарнитура» пропало, захват продолжается с «образцы»», Системный звук захватывается по-прежнему

#### Scenario: Пропали колонки
- **GIVEN** идёт Лекция с устройства «Колонки», в системе есть ещё «Наушники USB»
- **WHEN** «Колонки» пропадают, а устройством по умолчанию становятся «Наушники USB»
- **THEN** захват переходит на «Наушники USB»
- **AND** Отметка и предупреждение гласят «Системный звук: устройство «Колонки» пропало, захват продолжается с «Наушники USB»»

### Requirement: Предупреждение о пропаже устройства остаётся до конца Сессии
Предупреждение о пропавшем устройстве SHALL оставаться на экране «Сессия» до конца Сессии, в том числе на паузе и после «Продолжить», и SHALL исчезнуть, когда Сессия закончилась. Новая Сессия начинается без старых предупреждений.

#### Scenario: Предупреждение переживает паузу и исчезает после «Стоп»
- **GIVEN** идёт Лекция, устройство Системного звука пропало, на экране предупреждение
- **WHEN** пользователь нажимает «Пауза», «Продолжить» и «Стоп»
- **THEN** на паузе и после «Продолжить» предупреждение на экране
- **AND** после «Стоп» и после следующего «Старт» предупреждения нет

### Requirement: Название устройства и уровень сигнала каждого Источника
Во время Сессии Spook SHALL сообщать экрану «Сессия» название устройства каждого Источника и уровень его сигнала. Уровень приходит событием `levels`, пока Сессия идёт: для Источника — `rms` и `peak` в долях полной шкалы от 0 до 1; тишина даёт ровно ноль. Название устройства остаётся на экране и на паузе.

#### Scenario: Уровень синусоиды
- **GIVEN** идёт Лекция
- **WHEN** в Системном звуке полсекунды звучит синусоида амплитудой 0,5
- **THEN** приходит событие `levels` с `rms` около 0,3536 и `peak` около 0,5 для Источника `system`

#### Scenario: Тишина даёт нулевой уровень
- **GIVEN** идёт Лекция
- **WHEN** в Системном звуке тишина
- **THEN** приходит событие `levels` с данными `{"system": {"rms": 0.0, "peak": 0.0}}`

#### Scenario: Во Встрече уровень приходит для каждого Источника
- **GIVEN** идёт Встреча
- **WHEN** в Микрофоне тишина
- **THEN** приходит событие `levels` с данными `{"mic": {"rms": 0.0, "peak": 0.0}}`

#### Scenario: Название устройства остаётся на паузе
- **GIVEN** идёт Лекция с устройства «образцы»
- **WHEN** пользователь нажимает «Пауза»
- **THEN** экран по-прежнему показывает для Системного звука устройство «образцы»

### Requirement: «Старт» отклоняется, когда Источник нельзя захватить
Если Источник вида Сессии нельзя захватить, «Старт» SHALL быть отклонён с причиной и SHALL NOT оставлять следов: Заметка не остаётся, уже начатый захват останавливается, состояние — «нет Сессии», следующий «Старт» работает.

#### Scenario: Нет устройства вывода по умолчанию
- **GIVEN** в PipeWire нет устройства вывода по умолчанию
- **WHEN** пользователь нажимает «Старт» Лекции
- **THEN** команда отклонена с причиной «Нет устройства для захвата: Системный звук — нет устройства вывода по умолчанию»
- **AND** состояние остаётся «нет Сессии»

#### Scenario: PipeWire недоступен
- **GIVEN** программа `pw-dump` не найдена
- **WHEN** пользователь нажимает «Старт» Лекции
- **THEN** команда отклонена с причиной «PipeWire недоступен: не найдена программа pw-dump»

#### Scenario: Закреплённого устройства нет
- **GIVEN** за Системным звуком закреплено `alsa_output.usb-dac`, которого в системе нет
- **WHEN** пользователь нажимает «Старт» Лекции
- **THEN** команда отклонена с причиной «Нет устройства для захвата: Системный звук — закреплённое устройство «alsa_output.usb-dac» не найдено»
- **AND** состояние остаётся «нет Сессии»

#### Scenario: Встреча без Микрофона
- **GIVEN** Микрофон захватить нельзя
- **WHEN** пользователь нажимает «Старт» Встречи
- **THEN** команда отклонена с причиной, которая называет Микрофон
- **AND** состояние — «нет Сессии», папка Встреч пуста, захват Системного звука остановлен
- **AND** следующий «Старт» Лекции начинает Сессию

### Requirement: Звук живёт только в памяти
Spook SHALL NOT записывать захваченный звук на диск, даже временно: звук существует в памяти, пока распознаётся Реплика, и никуда не передаётся.

#### Scenario: Лекция на настоящем PipeWire не оставляет файлов
- **GIVEN** настоящий PipeWire с виртуальным устройством вывода, в которое воспроизводится тон
- **WHEN** пользователь проводит Лекцию от «Старт» до «Стоп»
- **THEN** во временных каталогах и в рабочем каталоге службы не появилось новых файлов
- **AND** программы захвата не держат открытым ни одного файла, в который можно писать
- **AND** в журнале службы нет данных звука
