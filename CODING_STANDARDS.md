# Стандарты кода

- Имена в коде английские, по словарю: Сессия → Session (kind: meeting, lecture); Источник → Source (system, mic); Реплика → Utterance; Транскрипт → Transcript, абзац → Paragraph; Живой текст → live events; Заметка → Note; Тема → topic; Ссылка → link; Выжимка → Summary; Агент → Agent; Скилл → skill; Словарь терминов → TermsDictionary; Хранилище → Vault; Вики → Wiki; Пауза → pause; автостоп → auto_stop; отставание → backlog.
- В коде (Python, JS, CSS, шаблоны, shell) нет комментариев и докстрингов: «почему» выражается именами и тестами. Директивы инструментов (`# noqa`, `# type: ignore`) и shebang — не комментарии. Вендорные `src/spook/static/htmx*.js` не трогаются. Правило проверяет быстрый тест `tests/test_no_comments.py`.
- Тесты — только на этих швах: HTTP-интерфейс службы с подменами входа звука, распознавателя, внешних программ и часов; контрактные тесты распознавателя; Playwright. Швы согласованы, спрашивать не нужно. Тесты, которые проверяют сам код, а не поведение, под это правило не подпадают.
- Звук в тестах идёт только в виртуальные устройства, созданные на время теста; устройства пользователя по умолчанию не меняются.
- В тестах настройки, журналы и модель — во временных каталогах, не в `~/.config/spook/`, `~/.local/state/spook/`, `~/.local/share/spook/`.
- Медленные тесты (модель, PipeWire, браузер, настоящий Claude Code) помечаются маркерами из `pyproject.toml` и по умолчанию не запускаются.
