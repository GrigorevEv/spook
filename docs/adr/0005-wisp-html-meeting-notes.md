# Заметка Встречи хранится в Wisp как самостоятельная HTML-страница

Пользователь читает Заметки в разделе «Встречи» Wisp. Ему нужен Транскрипт сразу после завершения Сессии, даже если Агент недоступен. Spook сохраняет текст Встречи в HTML с первой Реплики. После «Стоп» публикует страницу и обновляет раздел штатной командой Wisp. Выжимку и предложенную Тему Spook получает от Агента по ADR-0004 и добавляет на ту же страницу.

## Рассмотренные варианты

Markdown в Obsidian с экспортом в Wisp сохранил бы два экземпляра каждой Заметки. Для повторной Выжимки и восстановления после сбоя пришлось бы согласовывать их содержимое. Публикация только после успешного запуска Агента оставила бы пользователя без Транскрипта при ошибке модели. Пользователь выбрал одно постоянное Хранилище и независимую от Агента публикацию Транскрипта.

## Последствия

- Во время Встречи HTML хранится в `.spook/` внутри Wisp. Служба может продолжить Сессию после перезапуска. Звук остаётся в памяти по ADR-0001.
- При завершении Встречи Spook публикует страницу в `html/` и обновляет раздел и поиск командой `scripts/wiki_html.py index --html-only`. Сбой публикации допускает повтор по тому же идентификатору Встречи.
- Адрес опубликованной Заметки сохраняется при новом запуске Агента и уточнении Темы. Ссылки, которые пользователь сохранил сразу после «Стоп», продолжают открывать тот же Транскрипт.
- Существующие страницы Wisp принадлежат пользователю. Старые Заметки Markdown остаются по прежним путям.
