# Агент Встречи работает через Codex, Заметку сохраняет Spook

Пользователь выбрал Codex по подписке для Выжимки и Темы Встречи. После завершения Сессии Spook вызывает `codex exec` для одной Заметки. По умолчанию передаёт модель `gpt-6.2-astra` и явный `model_reasoning_effort="high"`. Это заменяет ADR-0003 и сохраняет роль пользовательского Скилла в подготовке Выжимки.

## Рассмотренные варианты

Права на чтение и изменение Хранилища, команды и сеть помогали Claude Code вести Вики Лекций. Для Встречи Spook передаёт Скилл, дату, имеющуюся Тему, Транскрипт, содержимое Словаря терминов, названия заметок Хранилища и ссылки Вики. Реплики могут содержать произвольные указания, поэтому Агент работает в отдельной папке с закрытым доступом к файловой системе, командной строке, сети процесса и MCP. Для сверки написания публичного термина Spook запрашивает встроенный поиск Codex по индексу в режиме `cached`. Скилл запрещает включать в поисковый запрос Реплики, имена коллег и внутренние сведения.

## Последствия

- В облако OpenAI передаётся перечисленный текст. Звук живёт только в памяти по ADR-0001.
- Codex возвращает Выжимку и Тему в JSON. Запись Заметки, сохранение свойств и Транскрипта, очистка Темы и согласование имени с интерфейсом и Журналом Агента принадлежат Spook.
- Запуски последовательны. Ошибка оставляет Транскрипт и прежнюю Выжимку доступными. Пользователь может выбрать модель и effort и повторить запуск.
- Для службы требуется Codex CLI с поддержкой закрытого профиля разрешений и структурированного ответа. Проверено на версии 0.172.0. Пользователь входит в Codex командой `codex login`. Для фонового запуска Spook использует файловую авторизацию Codex вне рабочего каталога модели.
