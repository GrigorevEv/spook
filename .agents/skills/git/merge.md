# Squash-merge PR

Влей PR squash-ем. PR — номер из просьбы; номера нет — PR текущей ветки. Только по прямой просьбе пользователя.

Не менять настройки репозитория, не использовать `--admin`, не обходить проверки, не трогать локальные ветки и рабочий каталог: основной разговор может в нём работать.

## Где выполнять

Работу выполняй в фоновом субагенте, не в текущем разговоре. Запусти одного субагента на той же модели и с тем же уровнем effort, что и текущий разговор. Передай ему абсолютный путь к этому файлу (`<корень репозитория>/.agents/skills/git/merge.md`), рабочий каталог и номер PR. Не жди его, продолжай разговор; когда он закончит, ответь пользователю его итогом дословно. Субагент выполняет шаги этого файла сам и других субагентов не запускает. Если запустить субагента нельзя — выполни шаги сам.

## Сообщение

Squash-коммит — про весь PR, по-английски:

```text
<заголовок PR> (#<N>)

- <что меняет PR и зачем, в повелительном наклонении>

Co-Authored-By: <модель> <почта>
```

- Пункты — из сообщений коммитов ветки: из тел, а если тел нет — из заголовков. Повторы, то, что отменил более поздний коммит, и merge-коммиты с основной веткой убрать.
- Трейлеры — `Co-Authored-By` из коммитов ветки, по одному на почту; имя — из самого нового коммита. Других трейлеров не добавлять.

## Шаги

1. Параллельно:
   - `gh pr view <N> --json number,title,url,state,isDraft,mergeable,headRefName,headRefOid` (без номера — `gh pr view`: PR текущей ветки);
   - `gh pr view <N> --json commits --jq '.commits[] | .messageHeadline, .messageBody, "---"'`;
   - `gh pr checks <N>`.
2. Остановиться, ничего не меняя, и кратко назвать причину, если PR не открыт, черновик, `mergeable` — `CONFLICTING` или проверка упала.
3. Проверки ещё идут — дождаться: `gh pr checks <N> --watch --fail-fast`. Упали — остановиться с причиной.
4. Тело сообщения — во временный файл (`mktemp`): со списка, без заголовка и без пустой строки перед списком (`gh` сам ставит её после заголовка).
5. `gh pr merge <N> -R GrigorevEv/spook --squash --match-head-commit <headRefOid> --subject "<заголовок PR> (#<N>)" --body-file <файл>`. `-R` — чтобы `gh` не трогал локальный репозиторий; без `--delete-branch` по той же причине. Отклонено — остановиться с причиной.
6. Ветка ещё есть на GitHub (`git ls-remote --heads origin <headRefName>` что-то выводит) — `git push origin --delete <headRefName>`.
7. Ответить: ссылка на PR, короткий хеш коммита (`gh pr view <N> --json mergeCommit --jq .mergeCommit.oid`) и команда, чтобы убрать локальную ветку: `git switch <основная> && git pull && git branch -D <headRefName>`. Без своих комментариев. При ошибке — кратко причиной.
